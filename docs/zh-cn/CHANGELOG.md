# 更新日志

[中文](/docs/zh-cn/CHANGELOG.md) | [English](/CHANGELOG.md) | [日本語](/docs/ja/CHANGELOG.md)

所有的Release版本的更新记录在此文件中。

如果您有问题、BUG反馈或功能建议，请前往 [GitHub问题页面](https://github.com/xlch88/YouTubeTweak/issues) 提交。

## [1.2.2] - 2026-07-25

### 更新

- **评论翻译:** 优化多项内容同时翻译时的处理效率，并更新手动翻译按钮图标。

### 添加

- **评论翻译:** 新增“为无需自动翻译的评论显示手动翻译按钮”选项，可自行隐藏同目标语言或“始终不翻译”语言的手动翻译入口。

### 修复

- **页面翻译:** 修复播放页标题和播放列表标题的译文显示问题，并改善与 DeArrow 的兼容性。
- **翻译设置:** 修复“始终不翻译的语言”未对评论、页面内容和字幕自动翻译统一生效的问题。
- **更新提示:** 修复补丁版本被误判为功能更新导致 `new` 标记显示不正确，以及更新日志版本范围不准确的问题。
- **画面缩放:** 修复拖拽已放大的画面时可能触发播放器其他操作的问题。

## [1.2.1] - 2026-07-21

### 更新

- **广告屏蔽:** 移除了视频广告屏蔽功能，建议使用其他插件进行替代。
- **评论翻译:** 将评论译文标记调整为灰色虚线下划线。

### 添加

- **页面翻译:** 新增视频列表标题、播放页标题和视频描述翻译，并支持翻译 YouTube 已提供的视频摘要。
- **外观:** 新增 Logo 国家/地区标识自定义功能，可将 YouTube Logo 旁的标识替换为指定文字。
- **更新提示:** 新增禁用更新提示选项，可关闭扩展图标上的 `new` 标记和未读更新日志自动打开。

### 修复

- **字幕翻译:** 修复字幕译文中 `&amp;` 等字符实体原样显示的问题。

## [1.2.0] - 2026-07-18

### 更新

- **安装引导:** 根据 Chrome、Edge 和 Firefox 显示对应的扩展图标提示，优化安装后的操作指引。
- **设置界面:** 优化卡片、滚动条、倍速按钮和配置管理布局，并将重置配置改为扩展内确认窗口。

### 添加

- **外观:** 新增“伪装 Premium Logo”选项，可将 YouTube 顶栏标志显示为 Premium 样式。

### 修复

- **更新日志:** 修复加载失败时仍被标记为已读，以及页面切换后可能重复自动打开的问题。
- **功能说明:** 修复英文界面的功能说明入口无法打开的问题。
- **滚动迷你播放器:** 修复 YouTube 环境光效果导致播放器画面变暗的问题。
- **字幕翻译:** 修复部分字幕事件缺少文本片段时可能触发异常的问题。

## [1.1.9] - 2026-07-03

### 添加

- **更新日志:** 新增内置更新日志弹窗和新版本未读提示，支持在扩展内查看当前版本变化。
- **设置界面:** 新增功能说明快捷入口，支持从各项设置直接打开对应帮助文档。
- **播放器按钮:** 新增播放器按钮显示模式，支持自动、隐藏和强制启用三种选项。

### 修复

- **自定义 CSS:** 修复自定义 CSS 编辑器在弹出窗口中可能报错的问题。

## [1.1.8] - 2026-07-03

### 更新

- **设置界面:** 优化配置导入导出和检查更新结果的提示显示。
- **播放器控制:** 优化倍速、旋转、镜像等自定义控制操作时的播放器控制栏显示。

### 添加

- **倍速控制:** 新增倍速滑块，支持拖拽连续调速、鼠标滚轮调速和自定义滚轮步长。
- **画面缩放:** 新增鼠标滚轮缩放视频画面，放大后可拖拽移动画面。
- **播放器功能按钮:** 新增视频截图按钮，支持保存当前视频画面为 PNG 图片。
- **播放器按钮:** 新增播放器按钮显示模式，支持自动、隐藏和强制启用。
- **自定义 CSS:** 新增自定义 CSS 编辑器，支持向 YouTube 注入自定义样式。
- **配置管理:** 新增导出/导入记忆数据的选项，支持随设置迁移分频道倍速、字幕等记忆。

## [1.1.7] - 2026-06-12

### 更新

- **广告屏蔽:** 新增 YouTube 购物推荐栏相关屏蔽规则。
- **禁用暂停:** 改进“视频已暂停，继续播放？”弹窗识别，避免误关其他弹窗。
- **记忆存储:** 将 500ms 内的重复写入合并处理，减少不必要的存储更新。
- **迷你播放器:** 简化弹出窗口中迷你播放器的尺寸显示。
- **i18n:** 更新新版播放器与回退设置相关翻译。
- **依赖:** 更新 WXT/构建工具，移除旧版浏览器全局变量兼容代码。

### 添加

- **迷你播放器:** 新增滚动迷你播放器，支持设置尺寸、位置、屏幕边距与触发距离。
- **音量增强器:** 新增真实音量增强功能，支持播放器内控制与自定义增强级别。
- **评论翻译:** 新增多行评论逐行显示译文的选项。
- **播放器界面:** 新增隐藏 YouTube 迷你播放器按钮的选项。
- **回退:** 新增回到旧版 YouTube 播放界面布局的选项。

### 修复

- **迷你播放器:** 改进进入/退出迷你播放器模式时的层级与布局恢复。
- **回退:** 修复开启旧版播放界面布局后，非 16:9 视频被塞进 16:9 外壳里显示的问题。
