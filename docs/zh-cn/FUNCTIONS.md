# 功能说明

[中文](/docs/zh-cn/FUNCTIONS.md) | [English](/FUNCTIONS.md) | [日本語](/docs/ja/FUNCTIONS.md)

YouTube Tweak 是一个用于增强 YouTube 网页版体验的浏览器扩展，在 Safari 版中显示为 YouTweak。本文按照扩展弹出面板里的分类顺序整理，重点说明每个功能有什么用、开启后会发生什么、适合什么场景，以及需要注意的限制。

本扩展主要在桌面版 YouTube 网页中生效。部分功能只在视频播放页、首页、搜索页、评论区或 Shorts 相关区域生效，具体范围会在对应功能里说明。

鼠标悬停到设置条目或卡片标题时，才会显示对应的问号按钮，点击即可打开本文对应位置。文中提到的默认状态，是指重置设置后使用的预设值；已有设置不会因为升级自动改变。

点击任意卡片标题可展开或收起其中的设置，也可以在标题获得焦点后按 Enter 或空格键操作。每张卡片会分别记住展开或收起状态，重新打开弹窗、切换分类或语言后仍会恢复。这些状态只保存在当前浏览器中。收起卡片只会隐藏设置内容，不会关闭功能或清除已经设置的值。

<a name="player"></a>

# 播放器

这一类功能用于增强视频播放页的观看体验，主要作用在 YouTube 播放器和视频播放页。

附属参数集中在主开关下方。关闭锁定画质、调速控件、迷你播放器、进度条或角落视频时间后，对应参数会置灰，但保留已经设置的值；关闭网速显示时，速率单位和流量统计选项也会置灰。

<a name="player-quality"></a>

## 锁定画质

<a name="player-quality-auto-switch"></a>

### 自动切换视频画质

默认: `关闭；目标画质为 1080p` | 版本：`v1.0.1 (2025-06-09)`

开启后，扩展会在每次进入或切换视频时，尝试把视频画质切换到你选择的清晰度。

适合的使用场景：

- 希望每个视频都尽量使用固定清晰度。
- 不想每次手动打开 YouTube 设置菜单调整画质。
- 网络环境稳定，想优先使用 1080p、1440p、4K 或更高画质。

可配置选项：

- 开关：控制是否自动切换视频画质。
- 目标画质：可选择 8K、4K、1440p、1080p、720p、480p、360p、240p 或 144p。

注意事项：

- 如果当前视频没有你选择的画质，扩展会自动降到这个画质以下可用的最高画质。
- 该功能只影响视频播放页。
- YouTube 本身可用的画质会受视频源、设备、网络和账号状态影响。

<a name="player-speed-button"></a>

## 播放速度

播放规则直接显示在前面，点击“调速控件”可展开倍速按钮、滑块和滚轮设置。收起这部分只会隐藏设置内容，不会关闭播放器中的调速控件。

<a name="player-speed-button-save"></a>

### 记住播放速度

默认: `开启；按频道记忆开启` | 版本：`v1.0.1 (2025-06-09)`

开启后，扩展会记住你通过扩展倍速按钮、滑块或滚轮设置的播放速度，并在之后的视频中自动恢复。

适合的使用场景：

- 总是用同一个倍速看大多数视频。
- 不同频道想使用不同倍速。
- 经常在学习类、娱乐类、音乐类频道之间切换。

可配置选项：

- 记住播放器速度：保存一个通用播放速度。
- 为每个频道分别记住播放速度：按频道保存播放速度。

注意事项：

- 同时开启通用记忆和分频道记忆时，分频道记忆优先。
- 使用 YouTube 自带菜单或快捷键调整的速度不会写入这份记忆。
- 恢复通用或分频道记忆的倍速，都需要扩展能识别当前视频所属频道。
- 记忆数据可以在通用设置里选择随设置一起导出。

<a name="player-speed-button-music"></a>

### 音乐视频加载时使用 1×

默认: `关闭` | 版本：`v2.0.0 (2026-09-14)`

开启后，加载视频时如果 YouTube 将它归类为音乐，扩展会以 1× 开始播放，优先于通用和分频道记忆的倍速。即使关闭速度记忆，这个选项也可以单独生效。

适合平时加速观看其他视频，但希望音乐以原速开始播放的情况。

注意事项：

- 加载后仍可手动调速，不会在播放过程中持续强制恢复为 1×。
- 自动使用 1× 不会覆盖已经保存的倍速；之后使用扩展调速控件修改速度时，仍按已开启的速度记忆选项保存。
- 识别依据是视频分类；包含音乐但没有被归类为音乐的视频，可能不会被识别。

<a name="player-speed-button-show"></a>

### 显示倍速按钮和倍速滑块

默认: `开启；显示 0.5x、1x、1.5x、2x；按钮自动折叠；倍速滑块开启；滚轮跟随按钮档位` | 版本：`v1.0.0 (2025-05-19)`

开启后，播放器控制栏里会显示自定义倍速按钮，用户可以直接点击按钮切换播放速度，不需要打开 YouTube 原本的设置菜单。

适合的使用场景：

- 经常在 1.5x、2x 等固定倍速之间切换。
- 看教程、直播回放、长视频时需要快速调速。
- 想把常用倍速放在播放器上直接点。

可配置选项：

- 显示倍速按钮/倍速滑块：控制播放器里是否显示扩展的倍速入口。
- 启用的按钮：点选需要显示的倍速，已选项会高亮；可选择 0.25x、0.5x、0.75x、1x、1.25x、1.5x、1.75x、2x、2.25x、2.5x、2.75x、3x、5x、10x。
- 折叠倍速按钮：可选择始终不折叠、始终折叠，或在播放器控制栏空间不足时自动折叠。
- 启用倍速滑块：开启后，可以按住倍速区域左右拖动，连续调整倍速。
- 鼠标滚轮步长：滚轮调速可以跟随已启用的倍速按钮，也可以使用 0.0625、0.125、0.25、0.5、1 或自定义步长。

注意事项：

- 拖动和滚轮调速都需要开启“显示倍速按钮/倍速滑块”和“启用倍速滑块”，并至少启用两个倍速按钮。
- 满足上述条件后，把鼠标放在倍速区域滚动滚轮即可调整播放速度。
- 拖动和滚轮调速的范围由已启用按钮中的最低、最高倍速决定，自定义滚轮步长也不能超出这个范围。例如只启用 1x、1.5x、2x 时，只能在 1x 到 2x 之间调整。
- 自定义滚轮步长支持很细的数值，但过小会让调整变慢，过大会让速度跳变明显。

<a name="player-volume-booster"></a>

## 音量增强器

<a name="player-volume-booster-gain"></a>

### 在播放器中增加真实音量增益

默认: `显示控制开启；音量增强关闭；增强级别 2x` | 版本：`v1.1.7 (2026-06-12)`

开启后，扩展可以在 YouTube 自带 100% 音量之上继续提高声音，并在播放器里显示一个音量增强按钮。

适合的使用场景：

- 视频本身声音太小。
- 系统音量已经调高，但 YouTube 仍然不够响。
- 想在播放器里快速调整音量增益。

可配置选项：

- 在倍速栏旁显示增强控制：控制播放器里是否显示音量增强按钮。
- 默认启用音量增强：进入视频时默认开启增强。
- 增强级别：可选择 1.25x 到 5x 的增益级别，每档间隔 0.25x。

使用方式：

- 点击播放器内的音量增强按钮，可以即时开关增强。
- 鼠标放在按钮上滚动滚轮，可以提高或降低增强级别。
- 增强关闭时，向上滚动会从 1.25x 开始启用；已经降到 1.25x 时，再向下滚动会关闭增强。
- 在播放器中调整的开关状态和增强级别会自动保存，后续视频也会沿用；只想增强当前视频时，使用完后需要手动关闭。

注意事项：

- 声音增强过高可能导致破音、噪声或音质变差。
- 部分浏览器可能要求用户先和页面交互后，声音增强才会真正开始工作。
- 如果隐藏播放器内按钮，默认启用仍然可以生效，但需要回到扩展设置中调整开关和增强级别。

<a name="player-other-max-volume"></a>

### 最大音量时使用真正 100% 音量

默认: `开启` | 版本：`v1.0.0 (2025-05-19)`

开启后，当 YouTube 音量条处于 100% 时，扩展会确保视频元素本身也处于真正的满音量状态。

适合的使用场景：

- YouTube 显示音量已满，但实际声音仍偏小。
- 想确保播放器没有被额外压低音量。

注意事项：

- 该功能只在 YouTube 音量条为 100% 时介入。
- 这不是额外放大音量；如果需要超过 100% 的音量，请使用“音量增强器”。
- 生效时音量滑块会用醒目的颜色提示。

<a name="player-subtitle"></a>

## 字幕

<a name="player-subtitle-save-status"></a>

### 记住字幕启用状态

默认: `开启；按频道记忆开启` | 版本：`v1.0.4 (2025-08-31)`

开启后，扩展会记录你是否打开了字幕，并在后续视频中尝试恢复字幕状态。

适合的使用场景：

- 常看外语视频，希望字幕默认保持打开。
- 部分频道需要字幕，部分频道不需要字幕。
- 不想每个视频都手动开关字幕。

可配置选项：

- 记住字幕启用状态：记录通用字幕状态。
- 为每个频道分别记住字幕启用状态：按频道记录字幕状态。

注意事项：

- 通用记忆和分频道记忆可独立开启；同时开启时，优先使用当前频道的记忆，没有时再使用通用记忆。
- 点击播放器字幕按钮、在播放器设置中开关字幕，或使用 YouTube 的 C 键成功切换字幕时，都会记录新的状态；自动恢复不会覆盖手动选择的记忆。
- 如果视频没有字幕，扩展无法强行生成 YouTube 字幕。
- 分频道记忆需要扩展能识别当前视频所属频道。

<a name="player-subtitle-save-language"></a>

### 为每个视频记住手动选择的字幕语言

默认: `关闭` | 版本：`v2.0.3 (2026-10-14)`

开启后，在普通视频播放页手动点击 YouTube 播放器设置、改选字幕语言时，会为这个视频保存选择。适合同一个视频反复观看时继续使用特定字幕，又不影响其它视频的情况。

注意事项：

- 只记录在播放器设置菜单中手动改选的字幕，不记录扩展自动选择或恢复的结果，也不会仅因为开关字幕就保存语言。
- 会区分人工字幕与自动生成字幕；手动选择 YouTube 自动翻译时，也会记住对应的翻译目标语言。
- 下次观看时，只有字幕已经开启才会恢复语言，不会为了恢复语言而打开字幕；字幕开关仍由 YouTube 和“记住字幕启用状态”控制。
- 当前视频的语言记忆优先于下方的“字幕优先语言”；原字幕或翻译目标不再可用时，再尝试优先语言列表。
- 这些单视频记忆只保存在当前浏览器的扩展本地存储中，不使用浏览器云同步；迁移时可在导出设置中勾选“同时导出记忆”。
- 关闭此选项会停止记录和恢复语言，但不会删除已经保存的记忆。

<a name="player-subtitle-priority"></a>

### 字幕优先语言

默认: `空列表` | 版本：`v2.0.3 (2026-10-14)`

为普通视频播放页设置字幕语言的选择顺序。例如依次添加中文、英语、日语后，扩展会先找中文字幕，没有时再找英语，最后找日语。

可配置选项：

- 添加语言：从下拉列表选择语言，名称按“当前界面语言中的称呼（该语言自身的称呼）”显示，例如“英语 (English)”。基础语言与对应的地区变体放在同一组内。
- 字幕类型：每种语言分别提供人工字幕和标有“自动生成”的选项，可同时加入并分别排序。“自动生成”指 YouTube 根据语音识别的字幕，不是把其它语言翻译过来的字幕。
- 优先顺序：拖动条目左侧的排序手柄，或点击上移、下移按钮调整；越靠上越优先。
- 移除语言：点击条目右侧的移除按钮，不再自动选择这一项。

注意事项：

- 候选语言来自扩展内置语言列表，不是当前视频的字幕清单；添加某种语言不代表视频一定提供这种字幕。
- 选择基础语言时，会尝试该语言及其地区变体；选择具体变体时，会缩小匹配范围。人工字幕与自动生成字幕不会互相替代，需要分别添加。
- 只在字幕开启时选择语言，不改变字幕开关状态，也不会自动开启 YouTube 自动翻译。
- 当前视频有可用的手动语言记忆时，优先恢复记忆；没有可用记忆时，才按列表顺序选择。
- 没有匹配字幕时保留 YouTube 原有选择。在当前视频中手动改选字幕后，扩展不会再用优先列表覆盖它。
- 该功能负责选择字幕语言，与“翻译”分类中的字幕翻译开关相互独立。

<a name="player-function-buttons"></a>

## 功能按钮

旋转、镜像、截图和页内全屏按钮可以分别开启。功能按钮组可以选择始终不折叠、始终折叠，或在播放器控制栏空间不足时自动折叠，默认使用自动折叠；独立的页内全屏按钮不属于这个折叠组。

<a name="player-function-buttons-rotate"></a>

### 旋转视频按钮

默认: `关闭` | 版本：`v1.0.9 (2025-11-22)`

开启后，播放器里会出现旋转按钮。每点击一次，视频画面旋转 90 度。

适合的使用场景：

- 视频方向上传错误。
- 想横屏观看竖屏内容，或临时调整观看方向。

注意事项：

- 旋转只影响当前页面里的显示效果，不会修改视频本身。
- 旋转 90 度或 270 度时，扩展会尽量缩放画面以适配播放器区域。

<a name="player-function-buttons-mirror"></a>

### 镜像视频按钮

默认: `关闭` | 版本：`v1.0.9 (2025-11-22)`

开启后，播放器里会出现镜像按钮。点击后可以水平翻转视频画面，再次点击可恢复。

适合的使用场景：

- 跟练舞蹈、健身、乐器动作时，希望左右方向更符合自己视角。
- 观看被镜像上传的视频时临时恢复方向。

注意事项：

- 镜像只影响显示效果，不会改变视频文件。
- 镜像可以和旋转同时使用。

<a name="player-function-buttons-screenshot"></a>

### 视频截图按钮

默认: `关闭` | 版本：`v1.1.8 (2026-07-03)`

开启后，播放器里会出现截图按钮。点击后会截取当前视频帧，并在新窗口中打开图片。

适合的使用场景：

- 保存视频中的某一帧画面。
- 做笔记、记录教程步骤或保存画面参考。

使用方式：

- 点击截图按钮后，扩展会打开一个新窗口显示截图。
- 在截图窗口中按 Ctrl+S 可以保存图片。

注意事项：

- 浏览器弹窗拦截可能会阻止截图窗口打开。
- 如果当前视频帧还没有准备好，截图可能失败。
- 截图文件名会尽量使用视频标题和当前播放时间。

<a name="player-function-buttons-in-page-fullscreen"></a>

### 页内全屏按钮

默认: `关闭` | 版本：`v2.0.0 (2026-09-14)`

开启后，普通视频播放页会在 YouTube 全屏按钮旁显示额外按钮。点击后，视频会铺满浏览器页面，仍然保留浏览器标签页和工具栏；再次点击可退出。

适合希望扩大视频画面，但仍需操作浏览器的情况。切换页面或关闭该设置时，会退出页内全屏。

进入页内全屏时会同时切换到剧场模式。再次点击按钮或关闭该设置退出时，会切回普通布局，即使进入前已经使用剧场模式，也不会保留原来的剧场模式。

<a name="player-button-display"></a>

## 按钮显示方式

点击卡片标题可展开原生按钮设置；收起卡片不会改变已经选择的显示方式。

<a name="player-button-display-native"></a>

### 控制播放器原生按钮显示

默认: `迷你播放器、画中画、剧场模式和电视播放按钮隐藏；其余自动` | 版本：`v1.0.0 (2025-05-19)`

该功能可以控制 YouTube 播放器中部分原生按钮的显示方式，让播放器控制栏更清爽。

适合的使用场景：

- 不使用某些 YouTube 原生按钮，希望减少干扰。
- 想强制显示某些被 YouTube 隐藏的按钮。
- 想让播放器控制栏更符合个人习惯。

可配置按钮：

- 自动播放按钮。
- 字幕按钮。
- 设置按钮。
- 迷你播放器按钮。
- 画中画按钮。
- 剧场模式按钮。
- 在电视上播放按钮。
- 全屏按钮。

可配置显示方式：

- 自动：保持 YouTube 默认显示方式。
- 隐藏：隐藏对应按钮。
- 强制启用：尽量让对应按钮保持可见。

注意事项：

- 字幕按钮只支持“自动”和“隐藏”，不提供“强制启用”。

## 画面缩放

<a name="player-video-zoom-wheel"></a>

### 用鼠标滚轮缩放视频画面

默认: `开启` | 版本：`v1.1.8 (2026-07-03)`

开启后，可以在视频画面上滚动鼠标滚轮来放大或缩小画面。放大后，可以拖动画面来移动观看区域。

适合的使用场景：

- 视频里有小字、小细节或远处画面需要看清。
- 想放大横屏视频中的局部区域。
- 看教学、录屏、监控画面时需要临时观察细节。

使用方式：

- 鼠标移到视频画面中间区域，向上滚动放大。
- 放大后向下滚动缩小，直到恢复原大小。
- 放大后按住鼠标左键拖动，可以移动画面。
- 进入滚动迷你播放器后，拖动会移动整个悬浮播放器，不再用于平移放大的画面。

注意事项：

- 最大可放大到 4 倍。
- 鼠标在播放器按钮、控制栏、链接、输入框等区域上时，不会触发画面缩放。
- 视频处于原始大小时，只有画面中央出现缩放提示的区域会接管滚轮；其它区域仍可正常滚动页面。
- 该功能只作用于当前视频画面，不改变视频源文件。

## 滚动迷你播放器

<a name="player-mini-player-scroll"></a>

### 滚动时让视频悬浮播放

默认: `关闭；480×270；右下角；边距 16px；触发距离 48px` | 版本：`v1.1.7 (2026-06-12)`

开启后，在视频播放页向下滚动离开播放器时，当前视频会变成悬浮迷你播放器，方便一边看视频一边浏览评论或推荐内容。

适合的使用场景：

- 看视频时想同时浏览评论区。
- 想在播放页往下翻内容，但不想让视频离开视线。
- 长视频播放时需要边看边找信息。

可配置选项：

- 大小：可选择 360×203、420×236、480×270、560×315、640×360、720×405；拖拽调整后的自定义尺寸也会显示在这里。
- 位置：可选择右下、底部居中、左下、右上、顶部居中、左上。
- 屏幕边距：分别设置水平 X 和垂直 Y 距离，单位为像素，以选定角落的页面可视区域边缘为起点；居中位置保持水平居中。
- 滚动超过播放器后激活：设置离开原播放器多少像素后进入迷你播放器，可设置 0 到 400 像素。

拖拽操作：

- 按住画面空白区域拖动，可以移动整个迷你播放器；播放器按钮、菜单和控制栏仍保留各自的操作。
- 拖动四个角中的任意一个，可以保持视频比例调整大小。尺寸受页面可视区域限制，空间足够时最小宽度为 260 像素。
- 松开鼠标后，按播放器中心落在页面可视区域的左上、右上、左下或右下，选择对应角落并保存 X、Y 边距；调整大小后也会保存尺寸。
- 拖动期间只预览，松开时才保存设置；按 Esc 可取消本次拖动并恢复原状。

注意事项：

- 该功能只在普通视频播放页生效。
- 全屏播放或画中画播放时不会进入迷你播放器。
- 迷你播放器上有关闭按钮，点击后本次滚动中会关闭悬浮；当你滚回播放器附近或切换视频后，会重新允许触发。
- 屏幕太小时，实际显示尺寸会自动缩小以避免超出屏幕。
- 悬浮期间，扩展的倍速按钮、功能按钮组和角落视频时间会隐藏。
- 实际显示宽度小于 520 像素时，会隐藏部分原生控制按钮，但仍保留字幕。控制栏沿用 YouTube 的自动显隐，不会因为悬浮而一直显示。
- 字幕会随播放器缩小，保留至少约 14 像素的可读字号，并让过长内容换行；退出迷你播放器后恢复原有字幕显示，不改写 YouTube 的字幕字号偏好。

这一类功能用于翻译视频列表标题、播放页文字、字幕和评论。所有翻译功能都会使用在线翻译服务，因此需要网络可用。

<a name="translate-settings"></a>

## 翻译设定

<a name="translate-settings-target-language"></a>

### 翻译目标语言

默认: `跟随 YouTube 语言` | 版本：`v1.0.9 (2025-11-22)`

该设置决定视频列表、播放页、字幕和评论要翻译成哪种语言。

可配置选项：

- 跟随 YouTube 语言：自动使用当前 YouTube 页面语言。
- 指定语言：从列表中选择固定目标语言。

- 如果原文语言和目标语言相同，部分翻译功能会跳过自动翻译。
- 更改目标语言后，已显示的旧翻译内容可能需要刷新页面或重新加载评论后才会更新。

<a name="translate-settings-never-translate"></a>

### 始终不翻译的语言

默认: `空列表` | 版本：`v1.1.2 (2025-11-26)`

该设置用于避免自动翻译某些语言的内容，适用于视频列表标题、播放页标题、简介、摘要、字幕和评论。

适合的使用场景：

- 你能直接阅读某些语言，不希望它们被自动翻译。
- 想避免中文评论、英文评论或其它熟悉语言重复出现译文。

注意事项：

- 语言判断会忽略同一种语言的地区差异，例如选择英语后，也会跳过其它地区的英语内容。
- 对属于排除列表、但不同于目标语言的评论，开启“翻译评论内容”和“为无需自动翻译的评论显示手动翻译按钮”后，若有不同于原文的译文，才会保留手动查看入口。
- 视频列表、播放页文字和字幕没有手动翻译入口；匹配排除语言时会直接保留原文。

- 关闭后，被排除的评论既不会自动显示译文，也不会显示手动翻译按钮；需要正常翻译的评论仍会自动翻译。

<a name="translate-comment-line-by-line"></a>

### 译文逐行显示在原文下方

默认: `开启` | 版本：`v1.1.7 (2026-06-12)`

开启后，对于包含多行内容的评论，扩展会尽量把每行译文放到对应原文下方，而不是把整段译文堆在评论末尾。

适合的使用场景：

- 翻译歌词、分段说明、长评论或多行时间轴。
- 希望原文和译文能逐行对照阅读。

注意事项：

- 该功能依赖“翻译评论内容”开启。
- 只有评论本身包含换行时，逐行显示才明显；普通单行评论仍会按普通方式显示译文。

# 洞察

这一类功能用于查看当前视频的资料、媒体格式、观看限制，以及不同语言下显示的封面、标题和描述。请先打开 YouTube 视频观看页，再打开扩展的洞察页；其它页面会提示先打开视频观看页。

<a name="insights-info"></a>

## 基本信息

<a name="insights-info-view"></a>

### 查看视频资料

默认: `打开洞察页时读取当前视频信息` | 版本：`v2.0.0 (2026-09-14)`

页面顶部显示视频封面、标题、频道和订阅人数，下面汇总观看次数、点赞数、视频秒数、订阅数及详细资料，适合快速核对当前视频的基本情况。

- 日期：显示发布日期；发布日期和上传日期不同时，括号内另列上传日期。
- 分类、用户名和频道 ID：帮助确认视频所属分类和发布频道。
- 可用地区：显示可用地区数与统计地区总数。
- 字幕 / 翻译：分别显示字幕轨道数量和可自动翻译的目标语言数量。
- 视频编码：列出已取得的视频格式所使用的编码名称。
- 播放规格：显示已取得格式中的最高帧率，以及是否包含 HDR 格式；这不表示播放器当前正在使用该规格。
- 标签：显示视频标签的数量。

读取中会显示加载状态；没有取得的信息以“—”或未知状态显示，不能当作数量为零或已经确认没有限制。

如果出现需要在页面确认的提示，请回到 YouTube 页面点击“我了解并希望继续观看”，然后重新打开洞察页。部分信息只有在完成页面上的确认后才能取得。

<a name="insights-video-formats"></a>

## 视频画质

<a name="insights-video-formats-view"></a>

### 查看视频格式和播放规格

默认: `分组收起；展开时补充读取媒体格式` | 版本：`v2.0.0 (2026-09-14)`

列出已取得的视频分辨率及其格式，按分辨率从高到低排列。同一分辨率有多个格式时会合为可展开的分组，只有一个格式时直接显示，适合比较同一画质下的编码、帧率和码率差异。

每条格式会按可取得的信息显示以下标识：

| 标识 | 含义 |
| --- | --- |
| 编码名称 | 视频使用的压缩格式，例如 H.264、VP9 或 AV1。 |
| FPS | 每秒画面数量，也就是帧率。 |
| HDR / SDR | 分别表示高动态范围或普通动态范围画面。 |
| kbps | 码率，即每秒传输的数据量；不同编码之间不能只凭这一数值判断清晰度。 |
| KB / MB | 已知的媒体大小，不一定包含另列的音频。 |
| itag | YouTube 用来区分媒体格式的编号。 |
| A/V | 此条格式同时包含画面和声音。 |
| Premium | YouTube 列出的 Premium 增强码率画质。 |

首次展开视频画质或音频格式时，会补充读取两类媒体格式。加载期间会显示提示；加载失败时，可收起后再次展开重试。列表用于查看信息，列出了某项 Premium 画质不代表当前账号已获得使用资格。

<a name="insights-audio-formats"></a>

## 音频格式

<a name="insights-audio-formats-view"></a>

### 查看音频规格

默认: `分组收起；展开时补充读取媒体格式` | 版本：`v2.0.0 (2026-09-14)`

列出已取得的音频格式，按码率从高到低排列。同一编码有多个格式时会合为可展开的分组，只有一个格式时直接显示，适合比较音频编码及声音规格。

除编码、码率、媒体大小和格式编号外，还可能显示采样率、声道数、质量等级和 DRC 标识。kHz 表示采样率，ch 表示声道数；DRC 表示该音频带有动态范围压缩，用于缩小较轻和较响声音之间的音量差异。只有 YouTube 提供了相应资料时才会显示这些内容。

“可翻译”表示该字幕可以继续翻译成其它语言，不代表视频已经提供所有目标语言的独立字幕。这里查看的是字幕资料，实际开启字幕和选择字幕语言仍在播放器中操作。

### 查看播放限制和可用能力

默认: `收起；记住展开或收起状态` | 版本：`v2.0.0 (2026-09-14)`

“限制”面板带有红色图标，集中展示视频的观看限制和可用能力。勾号表示该项成立，叉号表示不成立，“?” 表示尚未确认；读取中会显示加载状态。颜色还会区分有利状态和限制状态，因此勾号不一定代表没有限制，例如“年龄限制”打勾表示存在年龄限制。

将鼠标放在某项上可查看简短说明，各项含义如下：

| 项目 | 含义 |
| --- | --- |
| 无地域限制 | 是否在统计范围内的所有国家和地区可观看。 |
| 家庭友好 | YouTube 是否将视频标记为适合家庭观看。 |
| 评论功能 | 是否取得可用的评论入口或评论信息，有时还会显示评论数量。 |
| Premium 画质 | 是否列出了 Premium 增强码率画质。 |
| 转写文稿 | 是否提供转写文稿入口。 |
| 允许剪辑 | 是否提供从该视频创建剪辑的入口。 |
| 故事板 | 进度条是否提供画面预览缩略图。 |
| 登录限制 | 是否存在独立于年龄验证的登录观看要求。 |
| 紫砂警告 | 是否出现与自伤、自杀等危机内容相关的提醒或求助信息。 |
| 版权禁播 | 是否提示因版权原因无法播放。 |
| 社区准则禁播 | 是否提示因违反社区准则无法播放。 |
| 其他播放限制 | 是否存在未归入其它已识别类别的播放限制。 |
| 年龄限制 | 是否要求达到观看年龄或完成年龄确认。 |
| 不公开视频 | 是否标记为不公开，通常需要通过链接访问。 |
| 私享视频 | 是否标记为私享，仅发布者及获准的观看者可访问。 |
| 会员专属 | 是否提示需要频道付费会员资格。 |
| 儿童内容 | 是否被识别为儿童内容，相关互动和播放能力可能受 YouTube 限制。 |
| 允许嵌入 | 是否允许在其它网站嵌入播放。 |
| 广告投放 | 当前取得的信息中是否包含广告投放资料；没有资料不等于确认视频不能盈利。 |
| 允许 Shorts | YouTube 是否将视频标记为可用于 Shorts。 |

这些标记用于了解当前取得的信息，不会绕过登录、年龄、会员、地区或其它观看限制。未知状态也不能作为存在或不存在某项限制的结论。

<a name="insights-language-versions"></a>

## 语言版本

<a name="insights-language-versions-query"></a>

### 选择语言并分批查询

默认: `手动开始；语言选择收起；预选剩余热门前 10 种；首次最多加载 10 种；后续每批 10 种` | 版本：`v2.0.0 (2026-09-14)`

此面板位于洞察页最末，用于比较 YouTube 在不同语言下显示的封面、标题和描述。选择和加载控件放在结果列表下方，只有点击加载按钮才会查询。

- 要查询的语言：单行入口显示已选数量，点击后展开多选列表。按住 Ctrl/⌘ 可多选，Shift 可连选，也可以使用“全选”和“清空选择”。已加载或从缓存恢复的语言会从候选列表中移除。
- 后续每批：可选择每批最多加载 5、10、20 或 50 种语言。修改数量时会重新选择对应数量的剩余热门语言，但不会自动开始查询。
- 加载按钮：按列表顺序处理已选中且尚未加载的语言。没有已加载结果时使用首次加载上限；恢复缓存后则按“继续加载”的每批数量处理。当前选择全部成功加载后，会预选接下来一批剩余语言，仍需再次点击才继续；只完成当前选择不会显示“所有语言已加载完成”。
- 停止：停止当前批次后续的查询；已经发出的请求会先完成，因此点击后可能短暂显示“正在停止”。已取得的结果会保留。

查询逐个进行，每种语言完成后立即开始下一种，中间不额外停顿。查询期间不能更改语言选择或每批数量。关闭弹窗也会停止后续查询，但已经发出的请求可能仍会完成。某种语言查询失败会停止当前批次，稍后可继续重试；被 YouTube 限制时会显示提示并暂停查询 60 秒。如果视频已切换或已离开观看页，需要重新打开洞察后再查询。

请勿过快或频繁使用此功能，以免被 YouTube 拦截。未提供本地化内容时，YouTube 可能返回原始版本，因此结果不能用于确认作者具体提供了哪些翻译。

语言按估算互联网使用人数排序，地区变体放在最后。排序数据改编自 [OBDILCI V6（2025 年 7 月）](https://www.obdilci.org/projects/main/)，采用[原始表格的 INTERNAUTES L1+L2 人数列](https://www.obdilci.org/wp-content/uploads/2025/07/ResultsV6.xlsx)，统计联网的母语及第二语言使用者估算人数，并非全球去重后的独立人数。少数合并或缺失语言使用 [CLDR 48 语言人口](https://raw.githubusercontent.com/unicode-org/cldr/release-48/common/supplemental/supplementalData.xml)乘以[世界银行联网率（IT.NET.USER.ZS）](https://data.worldbank.org/indicator/IT.NET.USER.ZS)，按比例拆分或补估。改编后的排序数据继续采用 [CC BY-SA 4.0 许可](https://creativecommons.org/licenses/by-sa/4.0/)。

<a name="insights-language-versions-view"></a>

### 查看封面、标题和描述

默认: `取得结果后显示；描述收起` | 版本：`v2.0.0 (2026-09-14)`

结果分为“封面”和“标题与描述”两个区域，分别合并相同内容，并列出各自包含的语言，适合快速找出不同语言下的内容差异。

不同封面每张独占一行并占满宽度，相同封面合并显示；点击封面会在新标签页打开图片。标题和描述按相同组合合并，点击标题可展开或收起描述，同时只能展开一条，展开另一条会自动收起上一条。没有描述时会显示“没有描述”。

查询进度会显示已查询语言数及合并后的版本数；版本数按封面、标题和描述的完整组合计算，可能与单独的封面数或文字组合数不同。结果和展开的描述随内容自然增高，统一使用弹窗主区域滚动，不设置独立的内层滚动条。

<a name="insights-language-versions-cache"></a>

### 复用本地查询结果

默认: `按视频保存在本浏览器本地；有效期 60 分钟；打开弹窗时检查并清理` | 版本：`v2.0.0 (2026-09-14)`

已经查询成功的结果会自动缓存，重新打开弹窗时可直接恢复，减少重复查询。打开弹窗时，如果当前视频命中有效缓存，该视频全部仍有效的语言结果会按上述有效期重新续期；其它视频的缓存不会续期，过期结果也不会恢复为有效。

弹窗保持打开时不会定时清理缓存。恢复结果后，对应语言从候选列表中移除，并按查询功能的预选规则选择剩余热门语言；全部语言已有有效缓存时，不再预选候选语言。

## 更新

<a name="general-update-notice-disable"></a>

### 禁用更新提示

开启后，扩展不再用扩展图标上的 `new` 标记提醒你阅读新版本说明，点击扩展图标时也不会因为有未读说明而自动打开更新日志。

适合的使用场景：

注意事项：

- 这个选项只关闭新版本说明提醒，不会阻止浏览器检查、下载或安装扩展更新。
- 关闭提醒后，仍然可以在“关于”中手动查看更新日志，也可以点击版本号手动检查更新。

默认: `检测到新版本时自动显示` | 版本：`v1.0.1 (2025-06-09)`

可用操作：

- 查看更新日志。
- 立即更新。

- 点击“立即更新”会让扩展重新加载，并在更新完成后刷新已打开的 YouTube 标签页。
- “禁用更新提示”只关闭未读的新版本说明提醒，不会关闭浏览器已经检测到可用更新时的提示。

<a name="general-update-notice-reload-page"></a>

### YouTube 页面需要重新加载提示

默认: `自动检测并提示` | 版本：`v1.0.1 (2025-06-09)`

扩展更新后，已经打开的 YouTube 页面可能还在使用旧状态；修改需要重新加载才能完整生效的设置后，也会出现重新加载提示。提示出现时可自行决定何时刷新。

适合的使用场景：

- 扩展刚更新，但 YouTube 页面里的功能看起来异常。
- 页面提示扩展已更新，需要重新加载。
- 修改翻译或 Logo 等设置后，希望让已经打开的页面使用新设置。

可用操作：

- 刷新当前页：只重新加载显示提示的 YouTube 页面。
- 刷新所有 YouTube 页面：在设置变更产生的提示中显示，一次重新加载浏览器内已打开的 YouTube 标签页。

注意事项：

- 设置面板中没有单独开关。
- 扩展更新导致连接失效时，提示只提供刷新当前页的按钮。
- 刷新会重新加载页面内容，可在完成当前浏览操作后再点击。
- 重新加载后，页面会使用新的扩展状态。

<a name="general-update-notice-compatibility"></a>

### 兼容性警告

默认: `开启字幕翻译或伪装 Premium Logo 时显示` | 版本：`v1.1.3 (2025-12-03)`

当开启字幕翻译或伪装 Premium Logo 时，通用页面会显示警告提示。

原因说明：

- 这些功能会调整 YouTube 加载到页面中的字幕或品牌信息。
- 这种调整可能因为 YouTube 改版、网络问题或浏览器限制导致页面异常。

建议：

- 如果遇到视频无法播放、字幕异常、页面加载异常，或购买 Premium、加入频道会员、直播打赏等支付相关页面出现问题，先关闭字幕翻译和伪装 Premium Logo 进行排查。

## 插件设置

<a name="general-config-export"></a>

### 导出设置

默认: `仅导出普通设置；不包含记忆` | 版本：`v1.0.1 (2025-06-09)`

可以把当前扩展设置导出为文本，方便备份、迁移到其他浏览器，或分享给其他用户。

可配置选项：

注意事项：

- 导出的内容会复制到剪贴板；如果复制失败，可以手动选择文本复制。
- 卡片展开状态、洞察查询缓存等本地界面数据不在此备份范围内。

<a name="general-config-import"></a>

### 导入设置

默认: `仅导入普通设置；记忆需要另行确认` | 版本：`v1.0.1 (2025-06-09)`

可以粘贴之前导出的设置文本，将设置恢复到当前浏览器。

注意事项：

- 导入失败时，通常是文本格式不正确或内容不完整。
- 如果导入内容包含云同步记忆或本地单视频记忆，面板会要求你额外确认是否导入这些记忆；不确认时仅导入普通设置。
- 确认后，备份中包含的记忆类别会整体替换当前对应记忆，而不是合并。备份中这一类别为空时，也会清空当前对应记忆。
- 备份没有包含的记忆类别保持不变，例如导入不含本地记忆的旧备份，不会清空现有单视频字幕语言记忆。
- 导入的单视频字幕语言记忆仍只保存在当前浏览器本地，不会转为云同步。

<a name="general-config-reset"></a>

### 重置设置

默认: `恢复普通设置；保留已有记忆` | 版本：`v1.0.0 (2025-05-19)`

可以把扩展设置恢复为默认值。

注意事项：

- 重置普通设置不会清空云同步记忆或本地单视频记忆；如果要迁移或覆盖记忆，请使用导入导出里的记忆选项。

## 安装欢迎页

### 首次安装提示
