# YouTweak 隐私政策

**生效日期：2026 年 7 月 24 日**

[English](../../en/help/apple-privacy.md) | [简体中文](../../zh-cn/help/apple-privacy.md) | [日本語](../../ja/help/apple-privacy.md)

本隐私政策适用于 iOS、iPadOS 和 macOS 平台上的 YouTweak 应用及其随附的 Safari 扩展（以下统称“YouTweak”）。

## 隐私摘要

YouTweak 的开发者不会收集、接收、存储、出售或出租您的个人数据，也不会将其用于开发者自身的目的。YouTweak 不要求注册账户，不包含广告、分析工具、跟踪器、遥测或后台诊断上报，也不运营用于接收用户数据的服务器或数据库。功能所需的第三方网络处理将在下文单独说明。

## 我们不收集的数据

开发者不会收集或保留任何个人数据或使用数据，包括但不限于：

- 姓名、电子邮件地址、电话号码或其他联系信息；
- 账户凭据、付款信息或购买记录；
- 精确位置或大致位置；
- 通讯录、照片、音频、摄像头或麦克风数据；
- 设备标识符、广告标识符或用于跟踪的标识符；
- 浏览历史、搜索历史、YouTube 观看记录或页面内容；
- 使用情况、性能、崩溃或其他诊断数据。

## 设备端处理与本地存储

在您明确授予 Safari 网站访问权限后，YouTweak 扩展会在 `*.youtube.com` 页面上运行。为了提供当前处于启用状态的功能，扩展可能会读取和修改当前 YouTube 页面的内容、页面地址以及相关网络请求和响应。这些处理在您的浏览器中进行，开发者不会接收这些内容，也不会将其保存到开发者控制的服务器。

您的扩展设置、功能偏好、缓存和版本提示状态（包括按 YouTube 频道保存的播放速度或字幕偏好）保存在 Safari 或 WebExtension 提供的本地存储或同步存储中。如果您启用了浏览器或系统的同步功能，平台提供商可能会根据其自身条款和隐私政策同步这些设置；开发者无法访问该同步数据。

## 网络连接与第三方服务

YouTweak 不会把数据发送给开发者，但下列功能会让您的设备直接连接到提供相关功能的第三方服务：

- **YouTube 和 Google 服务：** YouTweak 在 YouTube 网站上工作，并可能向 YouTube 发出提供所选功能所需的请求。当翻译功能处于启用状态时（部分翻译功能可能默认启用，您可以在设置中关闭），需要翻译的 YouTube 页面文本、评论或字幕可能会直接发送至 Google 翻译服务以返回翻译结果。开发者不会接收或保留这些内容。
- **GitHub：** 当您打开更新日志、帮助页面、源代码或问题反馈页面时，应用可能会从 GitHub 获取公开内容或在浏览器中打开 GitHub 页面。该请求不会包含您的 YouTweak 设置或 YouTube 页面内容。

第三方服务可能接收正常网络连接所必需的信息，例如 IP 地址和标准请求信息，并按照其各自的政策处理这些信息。您可以查阅 [Google 隐私权政策](https://policies.google.com/privacy) 和 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。Apple 也可能依据 [Apple 隐私政策](https://www.apple.com/legal/privacy/)单独处理 App Store、操作系统、同步或诊断信息；这些信息并非由 YouTweak 收集。YouTweak 不会添加用于广告或跨应用跟踪的标识符，也不会向广告商或数据经纪商共享数据。

Google、GitHub 和 Apple 提供的是独立服务，并非代表 YouTweak 开发者运营数据收集服务。开发者不会向广告、分析或其他第三方合作伙伴披露个人数据。如果 YouTweak 将来委托第三方代表开发者处理个人数据，开发者将要求该第三方提供与本政策相同或同等的保护，在处理开始前披露相关安排并更新本政策。

## 权限用途

YouTweak 仅请求实现核心功能所需的权限：

- **YouTube 网站访问权限：** 在您允许后读取和修改 YouTube 页面，以实现您启用的界面和播放体验功能；
- **存储权限：** 在浏览器提供的存储空间中保存设置、偏好和扩展状态；
- **标签页权限：** 打开帮助或项目链接，并在必要时更新与扩展功能相关的标签页。

这些权限不会用于建立浏览档案、跟踪您访问的其他网站，或把任何数据发送给开发者。您可以随时在 Safari 的扩展设置中撤销网站访问权限或停用 YouTweak。

## 数据保留、删除与您的选择

由于开发者不收集或保存您的数据，因此开发者没有可供保留、导出或删除的用户数据。

YouTweak 的重置功能会把功能配置恢复为默认值并覆盖已保存的配置，但不会删除全部扩展数据。若要删除其他本地设置和缓存，请使用 Safari 的网站或扩展数据管理功能并卸载 YouTweak；通过平台同步的设置可在相应的浏览器或系统同步设置中管理。您还可以停用翻译等可选功能以阻止后续翻译请求，或在 Safari 的扩展设置中撤销 YouTube 网站访问权限。

Google、GitHub 或 Apple 对其直接收到的信息拥有各自的保留和删除规则，开发者无法访问或代为删除这些信息。您可以通过上述第三方隐私政策中的隐私控制或联系方式，直接向相应服务查询、管理或请求删除其持有的信息。

## 儿童隐私

YouTweak 不专门面向儿童，也不会有意收集儿童或任何其他用户的个人数据。

## 安全

YouTweak 通过不运营数据收集服务器、优先在设备端处理数据、使用系统和浏览器提供的沙盒及存储机制，并将权限限制在核心功能所需范围内来降低隐私风险。

## 本政策的变更

如果 YouTweak 的数据处理方式发生变化，开发者会在新做法生效前更新本政策和 App Store 隐私信息，并在适用法律或 App Store 规则要求时征得用户同意。最新版本将始终公布在本页面，并标明新的生效日期。
