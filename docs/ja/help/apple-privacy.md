# YouTweak プライバシーポリシー

**発効日：2026 年 7 月 24 日**

[English](../../en/help/apple-privacy.md) | [简体中文](../../zh-cn/help/apple-privacy.md) | [日本語](../../ja/help/apple-privacy.md)

本プライバシーポリシーは、iOS、iPadOS、および macOS 向けの YouTweak アプリケーションと、それに同梱される Safari 拡張機能（以下、総称して「YouTweak」）に適用されます。

## プライバシーの概要

YouTweak の開発者は、利用者の個人データを収集、受信、保存、販売、貸与せず、開発者自身の目的にも使用しません。YouTweak はアカウント登録を必要とせず、広告、分析ツール、トラッカー、テレメトリ、バックグラウンドでの診断情報送信を含みません。また、ユーザーデータを受信するサーバーやデータベースを運用していません。特定の機能に必要な第三者によるネットワーク処理については、以下で個別に説明します。

## 収集しないデータ

開発者は、以下を含む個人データまたは利用データを収集、保持しません。

- 氏名、メールアドレス、電話番号、その他の連絡先情報。
- アカウント認証情報、支払い情報、購入履歴。
- 正確な位置情報またはおおよその位置情報。
- 連絡先、写真、音声、カメラ、マイクのデータ。
- デバイス識別子、広告識別子、追跡用識別子。
- 閲覧履歴、検索履歴、YouTube の視聴履歴、ページ内容。
- 利用状況、パフォーマンス、クラッシュ、その他の診断データ。

## デバイス上の処理とローカルストレージ

利用者が Safari の Web サイトアクセスを明示的に許可した後、YouTweak 拡張機能は `*.youtube.com` 上で動作します。現在有効になっている機能を提供するため、拡張機能は現在の YouTube ページの内容と URL、および関連するネットワークリクエストとレスポンスを読み取り、変更する場合があります。この処理は利用者のブラウザー内で行われます。開発者がこれらの内容を受信したり、開発者が管理するサーバーに保存したりすることはありません。

拡張機能の設定、機能設定、キャッシュ、およびバージョン通知の状態（YouTube チャンネルごとに保存される再生速度や字幕の設定を含みます）は、Safari または WebExtension が提供するローカルストレージまたは同期ストレージに保存されます。ブラウザーまたはシステムの同期機能を有効にしている場合、プラットフォーム提供者が自身の利用規約およびプライバシーポリシーに従ってこれらの設定を同期することがあります。開発者は、その同期データにアクセスできません。

## ネットワーク接続と第三者サービス

YouTweak が開発者にデータを送信することはありませんが、以下の機能では、利用者のデバイスが該当機能を提供する第三者サービスへ直接接続します。

- **YouTube および Google のサービス：** YouTweak は YouTube Web サイト上で動作し、選択された機能に必要なリクエストを YouTube に送信する場合があります。翻訳機能が有効な場合（一部の翻訳機能は初期状態で有効になっていることがあり、設定から無効にできます）、翻訳対象として選択された YouTube ページのテキスト、コメント、または字幕が、翻訳結果を返すために Google の翻訳サービスへ直接送信されることがあります。開発者はこれらの内容を受信、保持しません。
- **GitHub：** リリースノート、ヘルプ、ソースコード、または問題報告ページを開くと、アプリケーションは GitHub から公開コンテンツを取得するか、ブラウザーで GitHub ページを開く場合があります。このリクエストに YouTweak の設定や YouTube ページの内容は含まれません。

第三者サービスは、IP アドレスや標準的なリクエスト情報など、通常のネットワーク接続に必要な情報を受信し、それぞれのポリシーに従って処理する場合があります。[Google プライバシーポリシー](https://policies.google.com/privacy)および[GitHub プライバシーに関する声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)をご確認ください。Apple も [Apple プライバシーポリシー](https://www.apple.com/legal/privacy/)に従い、App Store、オペレーティングシステム、同期、または診断情報を別途処理する場合がありますが、これらは YouTweak が収集する情報ではありません。YouTweak は広告またはアプリをまたぐ追跡のための識別子を追加せず、広告主やデータブローカーとデータを共有しません。

Google、GitHub、および Apple は独立したサービスを提供しており、YouTweak の開発者に代わってデータ収集サービスを運営するものではありません。開発者は、広告、分析、その他の第三者パートナーに個人データを開示しません。将来、YouTweak が開発者に代わる個人データ処理を第三者へ委託する場合、開発者は当該第三者に本ポリシーと同一または同等の保護を求め、処理開始前にその取扱いを開示して本ポリシーを更新します。

## 権限の使用目的

YouTweak は、中核機能に必要な権限のみを要求します。

- **YouTube Web サイトへのアクセス：** 利用者の許可後、有効になっているインターフェース機能および再生機能を提供するために YouTube ページを読み取り、変更します。
- **ストレージ：** ブラウザーが提供するストレージに設定、選択内容、および拡張機能の状態を保存します。
- **タブ：** ヘルプまたはプロジェクトのリンクを開き、必要な場合に拡張機能に関連するタブを更新します。

これらの権限を、閲覧プロファイルの作成、YouTube 以外で閲覧した Web サイトの追跡、または開発者へのデータ送信に使用することはありません。Safari の拡張機能設定から、いつでも Web サイトへのアクセス権限を取り消すか、YouTweak を無効にできます。

## データの保持、削除、および利用者の選択

開発者は利用者のデータを収集、保存しないため、開発者が保持、エクスポート、または削除できるユーザーデータはありません。

YouTweak のリセット機能は、機能設定を初期値に戻して保存済み設定を上書きしますが、拡張機能のすべてのデータを削除するものではありません。その他のローカル設定やキャッシュを削除するには、Safari の Web サイトまたは拡張機能データの管理機能を使用したうえで、YouTweak をアンインストールしてください。プラットフォームによって同期された設定は、該当するブラウザーまたはシステムの同期設定から管理できます。また、翻訳などの任意機能を無効にして今後の翻訳リクエストを停止したり、Safari の拡張機能設定で YouTube Web サイトへのアクセス権限を取り消したりできます。

Google、GitHub、および Apple は、直接受信した情報に独自の保持および削除規則を適用します。開発者は、その情報にアクセスしたり、利用者に代わって削除したりすることはできません。上記の第三者ポリシーに記載されたプライバシー管理機能または連絡方法を使用して、該当サービスが保持する情報の開示、管理、または削除を直接依頼できます。

## 子どものプライバシー

YouTweak は子どもを特定の対象としておらず、子どもを含むいかなる利用者からも個人データを意図的に収集しません。

## セキュリティ

YouTweak は、データ収集サーバーを運用せず、デバイス上の処理を優先し、システムおよびブラウザーが提供するサンドボックスとストレージ機構を使用し、権限を中核機能に必要な範囲へ限定することで、プライバシー上のリスクを低減します。

## 本ポリシーの変更

YouTweak のデータ取扱方法が変更される場合、開発者は新しい取扱方法が有効になる前に本ポリシーと App Store のプライバシー情報を更新し、適用法または App Store の規則で必要とされる場合は同意を求めます。最新版は、改定された施行日とともに常に本ページで公開します。
