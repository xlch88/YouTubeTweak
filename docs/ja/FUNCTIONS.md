# 機能説明

[中文](/docs/zh-cn/FUNCTIONS.md) | [English](/FUNCTIONS.md) | [日本語](/docs/ja/FUNCTIONS.md)

YouTube Tweak は、YouTube ウェブ版の体験を強化するためのブラウザー拡張で、Safari 版では YouTweak と表示されます。本書は拡張機能のポップアップパネル内の分類順に整理し、各機能が何をするのか、有効化後に何が起きるのか、どのような場面に適しているのか、注意すべき制限は何かを重点的に説明します。

本拡張は主にデスクトップ版 YouTube ウェブで動作します。一部の機能は動画再生ページ、ホーム、検索ページ、コメント欄、または Shorts 関連領域でのみ動作します。具体的な範囲は各機能の説明で示します。

設定項目やカードの見出しにマウスを重ねると、その項目の疑問符ボタンが表示され、クリックすると本書の対応箇所を直接開けます。本書に記載するデフォルト状態は、設定をリセットした後に使用されるプリセット値を指します。既存の設定はアップグレードによって自動的に変更されません。

各カードの見出しをクリックすると、設定を開いたり閉じたりできます。見出しにフォーカスを合わせて Enter キーやスペースキーでも操作できます。開閉状態はカードごとに記憶され、ポップアップを開き直したり、分類や言語を切り替えたりしても復元されます。この状態は現在のブラウザー内にのみ保存されます。カードを閉じても設定が非表示になるだけで、機能が無効になったり、設定済みの値が消えたりすることはありません。

<a name="player"></a>

# プレーヤー

この分類の機能は動画再生ページの視聴体験を強化するためのもので、主に YouTube プレーヤーと動画再生ページに作用します。

関連する詳細設定は主スイッチの下にまとまっています。画質固定、速度コントロール、ミニプレーヤー、進行バー、角の動画時間を無効にすると、対応する設定はグレー表示になりますが、保存済みの値は保持されます。通信速度の表示をオフにした場合も、単位と通信量の設定がグレー表示になります。

<a name="player-quality"></a>

## 画質固定

<a name="player-quality-auto-switch"></a>

### 動画画質の自動切り替え

デフォルト: `オフ；対象画質は 1080p` | バージョン: `v1.0.1 (2025-06-09)`

有効にすると、拡張機能は動画に入るたび、または動画を切り替えるたびに、選択した画質へ切り替えようとします。

適した使用場面:

- すべての動画でできるだけ固定画質を使用したい。
- 毎回 YouTube の設定メニューを手動で開いて画質を調整したくない。
- ネットワーク環境が安定しており、1080p、1440p、4K、またはそれ以上の画質を優先したい。

設定可能な項目:

- スイッチ: 動画画質を自動切り替えするかどうかを制御します。
- 目標画質: 8K、4K、1440p、1080p、720p、480p、360p、240p、または 144p を選択できます。

注意事項:

- 現在の動画に選択した画質がない場合、拡張機能はその画質以下で利用可能な最高画質へ自動的に下げます。
- この機能は動画再生ページにのみ影響します。
- YouTube 自体で利用可能な画質は、動画ソース、デバイス、ネットワーク、アカウント状態の影響を受けます。

<a name="player-speed-button"></a>

## 再生速度

再生ルールが先に表示されます。「速度調整コントロール」を開くと、倍速ボタン、スライダー、ホイールを設定できます。この部分を閉じても、プレーヤーの速度コントロールは無効になりません。

<a name="player-speed-button-save"></a>

### 再生速度を記憶

デフォルト: `オン；チャンネル別の記憶はオン` | バージョン: `v1.0.1 (2025-06-09)`

有効にすると、拡張機能の倍速ボタン、スライダー、ホイールで設定した再生速度を記憶し、以後の動画で自動的に復元します。

適した使用場面:

- ほとんどの動画を常に同じ倍速で見る。
- チャンネルごとに異なる倍速を使いたい。
- 学習系、娯楽系、音楽系チャンネルを頻繁に切り替える。

設定可能な項目:

- プレーヤー速度を記憶: 共通の再生速度を 1 つ保存します。
- チャンネルごとに再生速度を個別に記憶: チャンネル別に再生速度を保存します。

注意事項:

- 共通記憶とチャンネル別記憶を同時に有効にした場合、チャンネル別記憶が優先されます。
- YouTube 標準のメニューやショートカットキーで変更した速度は、この記憶には保存されません。
- 共通記憶とチャンネル別記憶のどちらから速度を復元する場合も、拡張機能が現在の動画の所属チャンネルを識別できる必要があります。
- 記憶データは一般設定で設定と一緒にエクスポートできます。

<a name="player-speed-button-music"></a>

### 音楽動画の読み込み時に 1× を使用

デフォルト: `オフ` | バージョン: `v2.0.0 (2026-09-14)`

動画の読み込み時に YouTube の分類が音楽であれば、共通またはチャンネル別に記憶した速度よりも優先して 1× で再生を開始します。速度の記憶を無効にしていても、この設定は単独で動作します。

ほかの動画は倍速で見たいものの、音楽は元のテンポで再生を始めたい場合に適しています。

注意事項:

- 読み込み後も手動で速度を変更できます。再生中に継続して 1× に戻す機能ではありません。
- 自動で 1× にしても記憶済みの速度は上書きされません。その後、拡張機能の速度コントロールで変更した速度は、有効な速度記憶設定に従って保存されます。
- 判定には動画のカテゴリを使用するため、音楽を含んでいても音楽カテゴリでない動画は認識されない場合があります。

<a name="player-speed-button-show"></a>

### 倍速ボタンと倍速スライダーを表示

デフォルト: `オン；0.5x、1x、1.5x、2x を表示；ボタンは自動で折りたたむ；倍速スライダーはオン；マウスホイールはボタンの段階に追従` | バージョン: `v1.0.0 (2025-05-19)`

有効にすると、プレーヤー操作バーにカスタム倍速ボタンが表示されます。ユーザーは YouTube 標準の設定メニューを開かずに、ボタンを直接クリックして再生速度を切り替えられます。

適した使用場面:

- 1.5x、2x などの固定倍速を頻繁に切り替える。
- チュートリアル、ライブ配信のアーカイブ、長い動画を見るときに素早く速度調整したい。
- よく使う倍速をプレーヤー上に直接置きたい。

設定可能な項目:

- 倍速ボタン/倍速スライダーを表示: プレーヤー内に拡張機能の倍速入口を表示するかどうかを制御します。
- 有効なボタン: 表示したい速度を選択すると、その項目が強調表示されます。0.25x、0.5x、0.75x、1x、1.25x、1.5x、1.75x、2x、2.25x、2.5x、2.75x、3x、5x、10x を選択できます。
- 倍速ボタンの折りたたみ: 常に展開、常に折りたたむ、またはプレーヤー操作バーの空きが不足したときに自動で折りたたむ設定を選べます。
- 倍速スライダーを有効化: 有効にすると、倍速エリアを押したまま左右にドラッグして、連続的に倍速を調整できます。
- マウスホイールステップ: ホイールによる速度調整は、有効化された倍速ボタンに従うことも、0.0625、0.125、0.25、0.5、1、またはカスタムステップを使用することもできます。

注意事項:

- ドラッグとホイールによる速度調整には、どちらも「倍速ボタン/倍速スライダーを表示」と「倍速スライダーを有効化」をオンにし、少なくとも 2 つの倍速ボタンを有効にする必要があります。
- 上記の条件を満たすと、マウスを倍速エリアに置いてホイールをスクロールすることで再生速度を調整できます。
- ドラッグとホイールによる速度調整の範囲は、有効なボタンの最低速度と最高速度で決まります。カスタムホイールステップでも、この範囲を超えることはできません。例えば 1x、1.5x、2x のみを有効にした場合、1x から 2x の間でのみ調整できます。
- カスタムホイールステップは非常に細かい数値に対応しますが、小さすぎると調整が遅くなり、大きすぎると速度の跳ねが目立ちます。

<a name="player-volume-booster"></a>

## 音量ブースター

<a name="player-volume-booster-gain"></a>

### プレーヤー内で実際の音量ゲインを追加

デフォルト: `コントロール表示はオン；音量ブーストはオフ；ブーストレベルは 2x` | バージョン: `v1.1.7 (2026-06-12)`

有効にすると、拡張機能は YouTube 標準の 100% 音量を超えて音量を上げ、プレーヤー内に音量ブースターボタンを表示できます。

適した使用場面:

- 動画自体の音量が小さすぎる。
- システム音量を上げていても、YouTube の音がまだ足りない。
- プレーヤー内で音量ゲインを素早く調整したい。

設定可能な項目:

- 倍速バーの横にブースト操作を表示: プレーヤー内に音量ブースターボタンを表示するかどうかを制御します。
- デフォルトで音量ブーストを有効化: 動画に入ったときにデフォルトでブーストを有効にします。
- ブーストレベル: 1.25x から 5x までのゲインレベルを選択でき、各段階は 0.25x 間隔です。

使用方法:

- プレーヤー内の音量ブースターボタンをクリックすると、ブーストを即時にオン/オフできます。
- マウスをボタン上に置いてホイールをスクロールすると、ブーストレベルを上げ下げできます。
- ブーストがオフのときに上へスクロールすると、1.25x から有効になります。1.25x まで下げた状態でさらに下へスクロールすると、ブーストがオフになります。
- プレーヤー内で変更したオン/オフの状態とブーストレベルは自動保存され、以後の動画にも引き継がれます。現在の動画だけを強化したい場合は、使用後に手動でオフにする必要があります。

注意事項:

- 音量ブーストが高すぎると、音割れ、ノイズ、音質低下が起きる可能性があります。
- 一部のブラウザーでは、ユーザーが先にページと操作してからでないと、音量ブーストが実際に動作しない場合があります。
- プレーヤー内ボタンを非表示にしてもデフォルト有効は機能しますが、オン/オフとブーストレベルの調整には拡張機能の設定に戻る必要があります。

<a name="player-other-max-volume"></a>

### 最大音量時に本当の 100% 音量を使用

デフォルト: `オン` | バージョン: `v1.0.0 (2025-05-19)`

有効にすると、YouTube の音量バーが 100% のときに、拡張機能は動画要素自体も本当の最大音量状態になるようにします。

適した使用場面:

- YouTube では音量最大と表示されているが、実際の音がまだ小さい。
- プレーヤーが追加で音量を下げていないことを確認したい。

注意事項:

- この機能は YouTube の音量バーが 100% のときにのみ介入します。
- これは追加の音量増幅ではありません。100% を超える音量が必要な場合は「音量ブースター」を使用してください。
- 動作中は音量スライダーが目立つ色で示されます。

<a name="player-subtitle"></a>

## 字幕

<a name="player-subtitle-save-status"></a>

### 字幕の有効状態を記憶

デフォルト: `オン；チャンネル別の記憶はオン` | バージョン: `v1.0.4 (2025-08-31)`

有効にすると、拡張機能は字幕をオンにしているかどうかを記録し、以後の動画で字幕状態の復元を試みます。

適した使用場面:

- 外国語動画をよく見ており、字幕をデフォルトでオンにしておきたい。
- 一部のチャンネルでは字幕が必要で、一部のチャンネルでは不要。
- 動画ごとに字幕を手動でオン/オフしたくない。

設定可能な項目:

- 字幕の有効状態を記憶: 共通の字幕状態を記録します。
- チャンネルごとに字幕の有効状態を個別に記憶: チャンネル別に字幕状態を記録します。

注意事項:

- 共通の記憶とチャンネル別の記憶は個別に有効化できます。両方が有効な場合は現在のチャンネルの記憶を優先し、なければ共通の記憶を使用します。
- プレーヤーの字幕ボタン、プレーヤー設定での字幕のオン/オフ、または YouTube の C キーで字幕を実際に切り替えた場合に、新しい状態を記録します。自動復元は手動で選択した記憶を上書きしません。
- 動画に字幕がない場合、拡張機能は YouTube 字幕を強制生成できません。
- チャンネル別記憶には、拡張機能が現在の動画の所属チャンネルを識別できる必要があります。

<a name="player-subtitle-save-language"></a>

### 動画ごとに手動で選択した字幕言語を記憶

デフォルト: `オフ` | バージョン: `v2.0.3 (2026-10-14)`

有効にすると、通常の動画再生ページで YouTube のプレーヤー設定を手動でクリックして字幕言語を変更した際に、その動画の選択を保存します。同じ動画を繰り返し見る際に、他の動画に影響を与えず特定の字幕を使い続けたい場合に適しています。

注意事項:

- プレーヤー設定メニューで手動変更した字幕のみを記録します。拡張機能による自動選択や復元の結果は記録せず、字幕のオン/オフだけでは言語を保存しません。
- 手動で作成された字幕と自動生成字幕を区別します。YouTube の自動翻訳を手動で選択した場合は、翻訳先言語も記憶します。
- 次回の視聴では、字幕がすでにオンの場合にのみ言語を復元します。言語の復元のために字幕をオンにすることはなく、字幕のオン/オフは引き続き YouTube と「字幕の有効状態を記憶」で制御します。
- この動画の言語の記憶は、下の「字幕の優先言語」より優先されます。元の字幕や翻訳先が利用できなくなった場合は、優先言語リストを試します。
- 動画ごとの記憶は、現在のブラウザーの拡張機能のローカルストレージにのみ保存され、ブラウザーのクラウド同期は使用しません。移行する場合は、設定のエクスポートで「記憶も同時にエクスポート」にチェックしてください。
- このオプションをオフにすると言語の記録と復元を停止しますが、保存済みの記憶は削除しません。

<a name="player-subtitle-priority"></a>

### 字幕の優先言語

デフォルト: `空のリスト` | バージョン: `v2.0.3 (2026-10-14)`

通常の動画再生ページで字幕言語を選ぶ順序を設定します。例えば、中国語、英語、日本語の順に追加すると、拡張機能はまず中国語字幕を探し、なければ英語、最後に日本語を探します。

設定可能な項目:

- 言語を追加: ドロップダウンリストから言語を選択します。名前は「現在の表示言語での名称（その言語での名称）」で表示されます。例えば「英語 (English)」です。基本言語と対応する地域別の言語は同じグループに表示されます。
- 字幕の種類: 各言語に、手動で作成された字幕と「自動生成」と表示された字幕の選択肢があります。両方を追加し、個別に並べ替えられます。「自動生成」は YouTube が音声認識で生成した字幕を指し、他の言語から翻訳した字幕ではありません。
- 優先順位: 項目左側の並べ替えハンドルをドラッグするか、上へ移動、下へ移動ボタンをクリックします。上の項目ほど優先されます。
- 言語を削除: 項目右側の削除ボタンをクリックすると、その項目を自動選択しなくなります。

注意事項:

- 言語の候補は拡張機能内の言語リストであり、現在の動画の字幕一覧ではありません。言語を追加しても、その動画に該当する字幕があるとは限りません。
- 基本言語を選ぶと、その言語と地域別の言語を探します。特定の地域別言語を選ぶと、検索範囲が狭まります。手動で作成された字幕と自動生成字幕は相互に代用されず、それぞれ追加する必要があります。
- 字幕がオンの場合にのみ言語を選択します。字幕のオン/オフ状態は変更せず、YouTube の自動翻訳も自動的には有効化しません。
- 現在の動画に利用可能な手動選択の記憶があれば、先にその記憶を復元します。利用可能な記憶がない場合にのみ、リスト順で選択します。
- 一致する字幕がない場合は、YouTube の選択を維持します。現在の動画で字幕を手動変更した後は、拡張機能が優先リストで上書きすることはありません。
- この機能は字幕言語を選択するもので、「翻訳」カテゴリーの字幕翻訳スイッチとは独立しています。

<a name="player-function-buttons"></a>

## 機能ボタン

回転、ミラー、スクリーンショット、ページ内全画面の各ボタンは個別に有効化できます。機能ボタンのグループは、常に展開、常に折りたたむ、またはプレーヤー操作バーの空きが不足したときに自動で折りたたむ設定を選べます。初期設定は自動です。独立したページ内全画面ボタンは、このグループには含まれません。

<a name="player-function-buttons-rotate"></a>

### 動画回転ボタン

デフォルト: `オフ` | バージョン: `v1.0.9 (2025-11-22)`

有効にすると、プレーヤー内に回転ボタンが表示されます。クリックするたびに、動画画面が 90 度回転します。

適した使用場面:

- 動画の向きが誤ってアップロードされている。
- 縦向きコンテンツを横向きで見たい、または一時的に視聴方向を調整したい。

注意事項:

- 回転は現在のページ内の表示効果にのみ影響し、動画自体は変更しません。
- 90 度または 270 度回転した場合、拡張機能はプレーヤー領域に合うように可能な限り画面を拡大縮小します。

<a name="player-function-buttons-mirror"></a>

### 動画ミラーボタン

デフォルト: `オフ` | バージョン: `v1.0.9 (2025-11-22)`

有効にすると、プレーヤー内にミラーボタンが表示されます。クリックすると動画画面を水平反転し、もう一度クリックすると元に戻ります。

適した使用場面:

- ダンス、フィットネス、楽器の動きを真似るときに、左右方向を自分の視点に合わせたい。
- ミラー状態でアップロードされた動画を一時的に正しい向きへ戻したい。

注意事項:

- ミラーは表示効果にのみ影響し、動画ファイルは変更しません。
- ミラーは回転と同時に使用できます。

<a name="player-function-buttons-screenshot"></a>

### 動画スクリーンショットボタン

デフォルト: `オフ` | バージョン: `v1.1.8 (2026-07-03)`

有効にすると、プレーヤー内にスクリーンショットボタンが表示されます。クリックすると現在の動画フレームをキャプチャし、新しいウィンドウで画像を開きます。

適した使用場面:

- 動画内の特定のフレームを保存したい。
- メモ、チュートリアル手順の記録、画面参考の保存に使いたい。

使用方法:

注意事項:

- 現在の動画フレームがまだ準備できていない場合、スクリーンショットに失敗することがあります。
- スクリーンショットのファイル名には、できるだけ動画タイトルと現在の再生時間を使用します。

<a name="player-video-zoom-wheel"></a>

### マウスホイールで動画画面をズーム

デフォルト: `オン` | バージョン: `v1.1.8 (2026-07-03)`

適した使用場面:

- 動画内の小さい文字、細部、遠くの画面をはっきり見たい。
- 横向き動画の一部領域を拡大したい。
- 教学動画、画面録画、監視映像を見るときに一時的に細部を確認したい。

使用方法:

- マウスを動画画面の中央付近へ移動し、上にスクロールして拡大します。
- 拡大後は下にスクロールして縮小し、元のサイズに戻します。
- 拡大後にマウス左ボタンを押したままドラッグすると、画面を移動できます。
- スクロール時のミニプレーヤーでは、ドラッグするとフローティングプレーヤー全体が移動し、拡大した画面の表示領域は移動しません。

注意事項:

- 最大 4 倍まで拡大できます。
- マウスがプレーヤーボタン、操作バー、リンク、入力欄などの領域上にあるときは、画面ズームは発動しません。

<a name="player-mini-player"></a>

## スクロールミニプレーヤー

<a name="player-mini-player-scroll"></a>

### スクロール時に動画をフローティング再生

デフォルト: `オフ；480×270；右下；余白 16px；発動距離 48px` | バージョン: `v1.1.7 (2026-06-12)`

有効にすると、動画再生ページで下へスクロールしてプレーヤーから離れたときに、現在の動画がフローティングミニプレーヤーになり、動画を見ながらコメントやおすすめ内容を閲覧しやすくなります。

適した使用場面:

- 動画を見ながらコメント欄も閲覧したい。
- 再生ページを下へスクロールしても、動画を視界から外したくない。
- 長い動画の再生中に、見ながら情報を探したい。

設定可能な項目:

- サイズ: 360×203、420×236、480×270、560×315、640×360、720×405 を選択できます。ドラッグで調整したカスタムサイズもここに表示されます。
- 位置: 右下、下部中央、左下、右上、上部中央、左上を選択できます。
- 画面余白: 水平方向の X と垂直方向の Y の距離を、ピクセル単位で個別に設定します。選択した隅のページ表示領域の端を基準とし、中央の位置では水平方向の中央揃えを維持します。
- プレーヤーを超えてスクロールしたら有効化: 元のプレーヤーから何ピクセル離れたらミニプレーヤーに入るかを、0 から 400 ピクセルで設定します。

ドラッグ操作:

- 操作部品のない動画画面を押したままドラッグすると、ミニプレーヤー全体を移動できます。プレーヤーのボタン、メニュー、操作バーはそれぞれの操作を維持します。
- 四隅のいずれかをドラッグすると、動画の縦横比を保ってサイズを変更できます。サイズはページの表示領域内に制限され、十分なスペースがある場合の最小幅は 260 ピクセルです。
- マウスを離すと、プレーヤーの中心がページ表示領域の左上、右上、左下、右下のどこにあるかに応じて基準の隅を選び、X、Y の余白を保存します。サイズを変更した場合は、そのサイズも保存します。
- ドラッグ中はプレビューのみで、マウスを離したときに設定を保存します。Esc キーを押すと今回のドラッグを取り消し、元の状態に戻します。

注意事項:

- この機能は通常の動画再生ページでのみ動作します。
- 全画面再生中やピクチャーインピクチャー再生中はミニプレーヤーに入りません。
- ミニプレーヤーには閉じるボタンがあります。クリックすると今回のスクロール中はフローティングが閉じられます。プレーヤー付近へ戻るか動画を切り替えると、再び発動できるようになります。
- 画面が小さすぎる場合、実際の表示サイズは画面外にはみ出さないように自動的に縮小されます。
- フローティング再生中は、拡張機能の倍速ボタン、機能ボタングループ、角の動画時間が非表示になります。
- 実際の表示幅が 520 ピクセル未満の場合、一部の標準操作ボタンは非表示になりますが、字幕は表示されます。操作バーは YouTube の自動表示と非表示に従い、フローティング中に表示されたままにはなりません。
- 字幕はプレーヤーに合わせて縮小し、読みやすい文字サイズとして最低約 14 ピクセルを維持します。長い内容は折り返します。ミニプレーヤーを終了すると元の字幕表示に戻り、YouTube の字幕文字サイズの設定は変更しません。

# 翻訳

この分類の機能は、動画一覧のタイトル、再生ページのテキスト、字幕、コメントの翻訳に使用します。すべての翻訳機能はオンライン翻訳サービスを使用するため、ネットワークが利用可能である必要があります。

<a name="translate-settings"></a>

## 翻訳設定

<a name="translate-settings-target-language"></a>

### 翻訳先言語

デフォルト: `YouTube の言語に従う` | バージョン: `v1.0.9 (2025-11-22)`

この設定は、動画一覧、再生ページ、字幕、コメントをどの言語へ翻訳するかを決定します。

設定可能な項目:

- YouTube 言語に従う: 現在の YouTube ページ言語を自動的に使用します。
- 言語を指定: 一覧から固定の目標言語を選択します。

注意事項:

- 原文言語と目標言語が同じ場合、一部の翻訳機能は自動翻訳をスキップします。
- 目標言語を変更した後、すでに表示されている古い翻訳内容の更新には、ページの再読み込みやコメントの再読み込みが必要な場合があります。

<a name="translate-settings-never-translate"></a>

### 常に翻訳しない言語

デフォルト: `空のリスト` | バージョン: `v1.1.2 (2025-11-26)`

この設定は、特定言語の内容を自動翻訳しないために使用し、動画一覧のタイトル、再生ページのタイトル、説明、概要、字幕、コメントに適用されます。

適した使用場面:

- 直接読める言語があり、それらを自動翻訳したくない。
- 中国語コメント、英語コメント、またはその他の慣れた言語で翻訳文が重複して出るのを避けたい。

注意事項:

- 言語判定では同じ言語内の地域差が無視されます。たとえば英語を選択すると、他地域の英語コンテンツもスキップされます。
- 除外リストに含まれ、翻訳先言語とは異なる言語のコメントでは、「コメント内容を翻訳」と「自動翻訳が不要なコメントに手動翻訳ボタンを表示」を有効にし、原文と異なる翻訳文がある場合にのみ、手動で確認するための入口を残します。
- 動画一覧、再生ページのテキスト、字幕には手動翻訳の入口がありません。除外言語に一致した場合は、そのまま原文を保持します。

### 動画の概要を翻訳する

デフォルト: `オン` | バージョン: `v1.2.1 (2026-07-21)`

有効にすると、YouTube が通常動画の再生ページで動画概要を提供している場合、拡張機能は元の概要の近くに翻訳文を表示します。概要を折りたたんだ場合も展開した場合も、それぞれに適した翻訳文が表示されます。

適した使用場面:

- まず概要から外国語動画のおおまかな内容を把握したい。
- YouTube に概要が表示されているが、その言語を読みづらい。

注意事項:

- この機能は YouTube が概要を提供している通常動画の再生ページでのみ動作します。
- 拡張機能は既存の概要のみを翻訳し、概要がない動画に対して自動的に概要を生成しません。
- 翻訳文には「翻訳先言語」の設定を使用し、タイトル、説明、字幕、コメントの各翻訳オプションには依存しません。
- 概要がすでに翻訳先言語である場合、翻訳文が原文と同じ場合、または翻訳に失敗した場合、ページは元の概要を保持します。
- この機能を有効または無効にすると、ページに再読み込みの案内が表示されます。現在のページまたはすべての YouTube ページの再読み込みを選択できます。

適した使用場面:

- 外国語動画を見るときに字幕翻訳が必要。
- 元の字幕を残しつつ翻訳も見たい。
- 字幕を直接目標言語に置き換えたい。

設定可能な項目:

- 字幕翻訳を有効化: 動画字幕を翻訳するかどうかを制御します。
- 翻訳方式: 「バイリンガル翻訳」または「翻訳文のみ表示」を選択できます。

翻訳方式の説明:

注意事項:

- 字幕翻訳を有効または無効にすると、ページに再読み込みの案内が表示されます。現在のページまたはすべての YouTube ページの再読み込みを選択できます。
- 字幕内容が長すぎる場合や翻訳サービスが失敗した場合、拡張機能は元の字幕を保持します。
- 字幕翻訳はページ読み込み内容を調整する機能です。ページに異常が出た場合は、まずこの機能を無効にして確認できます。

## コメント翻訳

<a name="translate-comment-content"></a>

### コメント内容を翻訳

デフォルト: `オン` | バージョン: `v1.0.0 (2025-05-19)`

有効にすると、拡張機能はコメント欄内のコメントを自動翻訳し、コメント原文の近くに翻訳文を表示します。

適した使用場面:

- 多言語のコメント欄を閲覧する。
- 海外動画を見るときにコメント内容を素早く理解したい。
- YouTube 標準の翻訳ボタンを 1 件ずつクリックしたくない。

設定可能な項目:

- コメント内容を翻訳: コメントを自動翻訳するかどうかを制御します。
- 自動翻訳が不要なコメントに手動翻訳ボタンを表示: 自動翻訳の対象から除外されたコメントに、翻訳文を手動で確認するための入口を残します。具体的な条件は下記の説明を参照してください。
- 翻訳先言語: コメントをどの言語へ翻訳するかを決定します。
- 常に翻訳しない言語: 慣れた言語で翻訳文が自動表示されるのを避けます。

注意事項:

- 空白のコメントや数字、句読点のみのコメントはスキップされます。翻訳先言語と同じ言語のコメントにも、拡張機能の手動翻訳ボタンは表示されません。
- 翻訳文は、元のコメント内の絵文字、画像、リンク、文字スタイルを可能な限り保持します。翻訳文内の動画時間リンクも、クリックして対応する時刻へ移動できます。
- コメントの並び順変更、さらにコメントを読み込み、または YouTube によるコメント欄の動的更新後も、拡張機能は新しく出現したコメントを引き続き処理します。
- 翻訳サービスが利用できない場合、コメントは元のまま保持されます。
- コメント翻訳を有効または無効にすると、ページに再読み込みの案内が表示されます。現在のページまたはすべての YouTube ページの再読み込みを選択できます。

<a name="translate-comment-manual-button"></a>

### 自動翻訳が不要なコメントに手動翻訳ボタンを表示

有効にすると、コメントが「常に翻訳しない言語」に含まれ、翻訳先言語とは異なり、翻訳サービスが原文と異なる翻訳文を返した場合、コメントの横に手動翻訳ボタンが表示されます。クリックした後に、そのコメントの翻訳文が表示されます。

普段はその言語を直接読めるものの、ときどき個別のコメントの翻訳を確認したい場合に適しています。

注意事項:

- この機能には「コメント内容を翻訳」が有効である必要があります。
- 翻訳先言語と同じ言語のコメントには、このボタンは表示されません。空白のコメントや数字、句読点のみのコメントはスキップされ、翻訳文が原文と同じ場合もボタンは表示されません。
- 無効にすると、除外されたコメントには翻訳文も手動翻訳ボタンも表示されません。翻訳が必要なコメントは、引き続き通常どおり自動翻訳されます。

<a name="translate-comment-line-by-line"></a>

### 翻訳文を原文下に行ごとに表示

適した使用場面:

- 歌詞、段落付き説明、長いコメント、複数行のタイムラインを翻訳する。
- 原文と翻訳文を行ごとに対照して読みたい。

注意事項:

- この機能は「コメント内容を翻訳」が有効であることに依存します。
- コメント自体に改行が含まれる場合にのみ、行ごとの表示が明確になります。通常の 1 行コメントは従来どおり翻訳文を表示します。

- CSS を誤って書くと、YouTube ページの表示が異常になる可能性があります。
- スイッチをオフにすると、カスタムスタイルはページから削除されます。

<a name="insights"></a>

# インサイト

この分類の機能は、現在の動画の情報、メディア形式、視聴制限、異なる言語で表示されるサムネイル、タイトル、説明を確認するためのものです。まず YouTube の動画視聴ページを開いてから、拡張機能のインサイトを開いてください。その他のページでは、先に動画視聴ページを開くよう案内が表示されます。

<a name="insights-info"></a>

## 基本情報

<a name="insights-info-view"></a>

### 動画情報を確認

デフォルト: `インサイトを開いたときに現在の動画情報を取得` | バージョン: `v2.0.0 (2026-09-14)`

ページ上部に動画のサムネイル、タイトル、チャンネル、チャンネル登録者数が表示され、その下に視聴回数、高評価数、動画の長さ（秒）、チャンネル登録者数、詳細情報がまとめられます。現在の動画の基本情報を素早く確認するのに適しています。

- 日付: 公開日を表示します。公開日とアップロード日が異なる場合は、アップロード日も括弧内に表示します。
- カテゴリ、ユーザー名、チャンネル ID: 動画のカテゴリと公開チャンネルの確認に役立ちます。
- 利用可能な地域: 利用可能な地域数と集計対象の地域総数を表示します。
- 字幕 / 翻訳: 字幕トラック数と自動翻訳できる対象言語数をそれぞれ表示します。
- 動画コーデック: 取得済みの動画形式で使用されているコーデック名を一覧表示します。
- 再生仕様: 取得済みの形式での最高フレームレートと、HDR 形式が含まれるかを表示します。プレーヤーが現在その仕様を使用していることを意味するものではありません。
- タグ: 動画タグの数を表示します。

読み込み中は読み込み状態が表示されます。取得できなかった情報は「—」または不明な状態として表示され、数がゼロである、または制限がないと確認されたことを意味しません。

ページでの確認が必要という案内が表示された場合は、YouTube ページに戻って「理解したうえで視聴を続ける」をクリックし、インサイトを開き直してください。一部の情報は、ページでの確認が完了した後にのみ取得できます。

<a name="insights-video-formats"></a>

## 動画画質

<a name="insights-video-formats-view"></a>

### 動画形式と再生仕様を確認

デフォルト: `グループは折りたたみ状態；展開時に追加のメディア形式を取得` | バージョン: `v2.0.0 (2026-09-14)`

取得済みの動画の解像度と形式を、解像度の高い順に一覧表示します。同じ解像度に複数の形式がある場合は開閉できるグループにまとめ、形式が 1 つだけの場合はそのまま表示します。同じ画質でのコーデック、フレームレート、ビットレートの違いを比較するのに適しています。

各形式には、取得できた情報に応じて次のラベルが表示されます。

| ラベル | 意味 |
| --- | --- |
| コーデック名 | H.264、VP9、AV1 など、動画に使用されている圧縮形式。 |
| FPS | 1 秒あたりの画像数、つまりフレームレート。 |
| HDR / SDR | それぞれ高ダイナミックレンジと標準ダイナミックレンジの映像。 |
| kbps | ビットレート、つまり 1 秒あたりに転送されるデータ量。異なるコーデック間では、この値だけで画質を判断できません。 |
| KB / MB | 判明しているメディアサイズ。別に表示されている音声が含まれるとは限りません。 |
| itag | YouTube がメディア形式を区別するために使用する番号。 |
| A/V | この形式には映像と音声の両方が含まれます。 |
| Premium | YouTube に掲載されている Premium の高ビットレート画質。 |

動画画質または音声形式を初めて展開すると、両方のメディア形式を追加で読み込みます。読み込み中は案内が表示されます。読み込みに失敗した場合は、折りたたんでから再度展開すると再試行できます。一覧は情報の確認用であり、Premium 画質が掲載されていても、現在のアカウントで利用資格が得られたことを意味しません。

<a name="insights-audio-formats"></a>

## 音声形式

<a name="insights-audio-formats-view"></a>

### 音声仕様を確認

デフォルト: `グループは折りたたみ状態；展開時に追加のメディア形式を取得` | バージョン: `v2.0.0 (2026-09-14)`

取得済みの音声形式をビットレートの高い順に一覧表示します。同じコーデックに複数の形式がある場合は開閉できるグループにまとめ、形式が 1 つだけの場合はそのまま表示します。音声コーデックや音声仕様を比較するのに適しています。

コーデック、ビットレート、メディアサイズ、形式番号に加え、サンプリングレート、チャンネル数、品質レベル、DRC ラベルが表示されることもあります。kHz はサンプリングレート、ch はチャンネル数を表します。DRC は、小さい音と大きい音の音量差を縮めるダイナミックレンジ圧縮が音声に適用されていることを示します。これらは YouTube が対応する情報を提供している場合にのみ表示されます。

<a name="insights-subtitles"></a>

## 字幕

<a name="insights-subtitles-view"></a>

### 字幕の言語と種類を確認

デフォルト: `字幕情報がある場合に表示；グループは折りたたみ状態` | バージョン: `v2.0.0 (2026-09-14)`

コンパクトな複数列のレイアウトで字幕言語を一覧表示し、言語コード、音声からの自動生成かどうか、YouTube 自動翻訳に対応しているかを示します。動画にどの字幕が用意されているかを確認するのに適しています。

「翻訳可能」は、その字幕をさらに別の言語へ翻訳できることを示し、すべての対象言語の独立した字幕が動画に用意されていることを意味しません。ここでは字幕情報を確認でき、実際の字幕の有効化や言語選択は引き続きプレーヤーで行います。

<a name="insights-audio-tracks"></a>

## 音声トラック

<a name="insights-audio-tracks-view"></a>

### 音声トラックとデフォルトの音声を確認

デフォルト: `音声トラック情報がある場合に表示；グループは折りたたみ状態` | バージョン: `v2.0.0 (2026-09-14)`

取得した音声トラック名、デフォルトの音声トラックのマーク、各トラックのコーデックと形式数を一覧表示します。動画に異なる言語や音声のバージョンが用意されているかを確認するのに適しています。

完全なトラック名を取得できなかった場合は、番号、デフォルトの音声トラック、関連する字幕言語のみが表示されることがあります。ここでは取得できた音声トラック情報を表示し、プレーヤーの音声を切り替える機能はありません。

<a name="insights-regions"></a>

## 地域別の利用可否

<a name="insights-regions-view"></a>

### 利用可能な地域と利用できない地域を確認

デフォルト: `グループと地域一覧は折りたたみ状態` | バージョン: `v2.0.0 (2026-09-14)`

国や地域ごとの動画の利用可否を確認できます。地域制限がある場合は、同じパネル内で「利用可能な地域」と「利用できない地域」を左右に並べ、中央を縦線で区切り、それぞれの数を表示します。各列は個別に開閉でき、展開後はそれぞれ高さが制限され、内容が多い場合は縦スクロールバーを使用します。

一覧には地域名とコードを表示します。集計範囲内のすべての地域で利用可能な場合は「制限なし」、地域情報を取得できなかった場合は「—」と表示し、全地域で利用可能とは判断しません。ここでは地域情報を表示するだけで、YouTube の視聴制限は変更しません。

<a name="insights-restrictions"></a>

## 制限

<a name="insights-restrictions-view"></a>

### 再生制限と利用可能な機能を確認

デフォルト: `折りたたみ状態；展開・折りたたみ状態を記憶` | バージョン: `v2.0.0 (2026-09-14)`

「制限」パネルには赤いアイコンが付き、動画の視聴制限と利用可能な機能をまとめて表示します。チェックマークは該当する、バツ印は該当しない、「?」は未確認を示し、読み込み中は読み込み状態が表示されます。色でも利用に有利な状態と制限の状態を区別するため、チェックマークが必ずしも制限なしを示すとは限りません。例えば「年齢制限」のチェックマークは年齢制限があることを示します。

各項目にマウスを重ねると短い説明を確認できます。各項目の意味は次のとおりです。

| 項目 | 意味 |
| --- | --- |
| 地域制限なし | 集計範囲内のすべての国と地域で視聴できるかどうか。 |
| ファミリー向け | YouTube が動画をファミリー向けとして分類しているかどうか。 |
| コメント機能 | 利用可能なコメントの入口や情報を取得できたかどうか。コメント数が表示される場合もあります。 |
| Premium 画質 | Premium の高ビットレート画質が掲載されているかどうか。 |
| 文字起こし | 文字起こしへの入口が提供されているかどうか。 |
| クリップ作成可能 | この動画からクリップを作成する入口が提供されているかどうか。 |
| ストーリーボード | 進行バーに映像のプレビューサムネイルが用意されているかどうか。 |
| ログイン制限 | 年齢確認とは別に、視聴時のログインが要求されているかどうか。 |
| 自傷・自殺に関する警告 | 自傷や自殺などの危機的な内容に関する注意や支援情報が表示されているかどうか。 |
| 著作権による再生禁止 | 著作権上の理由で再生できないと案内されているかどうか。 |
| コミュニティ ガイドラインによる再生禁止 | コミュニティ ガイドライン違反で再生できないと案内されているかどうか。 |
| その他の再生制限 | 識別済みの他の分類に属さない再生制限があるかどうか。 |
| 年齢制限 | 視聴可能な年齢に達していることや、年齢確認の完了が要求されているかどうか。 |
| 限定公開動画 | 限定公開として分類されているかどうか。通常はリンクからアクセスする必要があります。 |
| 非公開動画 | 非公開として分類され、投稿者と許可された視聴者のみがアクセスできるかどうか。 |
| メンバー限定 | チャンネルの有料メンバーシップが必要と案内されているかどうか。 |
| 子ども向けコンテンツ | 子ども向けコンテンツとして識別されているかどうか。関連する操作や再生機能が YouTube により制限される場合があります。 |
| 埋め込み可能 | 他のウェブサイトでの埋め込み再生が許可されているかどうか。 |
| 広告配信 | 現在取得できた情報に広告配信の情報が含まれるかどうか。情報がないことは、その動画が収益化できないと確認されたことを意味しません。 |
| Shorts で利用可能 | YouTube が動画を Shorts で利用可能として分類しているかどうか。 |

これらのマークは現在取得できた情報を把握するためのもので、ログイン、年齢、メンバーシップ、地域、その他の視聴制限を回避するものではありません。不明な状態から、制限の有無を判断することもできません。

<a name="insights-language-versions"></a>

## 言語別バージョン

<a name="insights-language-versions-query"></a>

### 言語を選択して分割して取得

デフォルト: `手動で開始；言語選択は折りたたみ状態；未取得の人気上位 10 言語を選択；初回は最大 10 言語；以降は 1 回につき 10 言語` | バージョン: `v2.0.0 (2026-09-14)`

このパネルはインサイトの最後にあり、YouTube が異なる言語で表示するサムネイル、タイトル、説明を比較できます。選択と読み込みの操作は結果一覧の下に配置され、読み込みボタンをクリックしたときだけ取得を行います。

- 確認する言語: 1 行の入口に選択数を表示し、クリックすると複数選択リストが開きます。Ctrl/⌘ を押しながら複数選択、Shift を押しながら範囲選択ができ、「すべて選択」と「選択を解除」も利用できます。読み込み済み、またはキャッシュから復元した言語は候補から除かれます。
- 次回以降の件数: 1 回あたり最大 5、10、20、50 言語から選択できます。件数を変更すると、残りの上位言語からその件数を選択し直しますが、取得は自動で開始しません。
- 読み込みボタン: 選択した未読み込みの言語を一覧の順に処理します。読み込み済みの結果がない場合は初回の上限を使用し、キャッシュを復元した後は「続けて読み込む」の 1 回あたりの件数で処理します。現在の選択をすべて正常に読み込むと、残りの言語から次の分を選択しますが、続行には再度クリックが必要です。現在の選択を完了しただけでは「すべての言語を読み込みました」とは表示されません。
- 停止: 現在の処理の後続の取得を停止します。送信済みのリクエストは先に完了するため、クリック後に「停止中」と短時間表示される場合があります。取得済みの結果は保持されます。

取得は 1 件ずつ行い、各言語が完了したら追加の待ち時間を設けず、すぐに次の言語を開始します。取得中は言語の選択や 1 回あたりの件数を変更できません。ポップアップを閉じても後続の取得は停止しますが、送信済みのリクエストは完了する場合があります。いずれかの言語の取得に失敗すると現在の処理を停止し、後で再試行できます。YouTube による制限を受けた場合は案内を表示し、取得を 60 秒間休止します。動画を切り替えた場合や視聴ページを離れた場合は、インサイトを開き直してから取得する必要があります。

YouTube にリクエストをブロックされるおそれがあるため、短時間に何度も使用しないでください。翻訳されたコンテンツがない場合、YouTube が元のバージョンを返すことがあるため、この結果だけでは投稿者がどの翻訳を提供したかは確認できません。

言語は推定インターネット利用者数の順に並び、地域別の言語は最後に配置します。並び順のデータは [OBDILCI V6（2025 年 7 月）](https://www.obdilci.org/projects/main/)を改変したもので、[元の表の INTERNAUTES L1+L2 列](https://www.obdilci.org/wp-content/uploads/2025/07/ResultsV6.xlsx)を使用しています。これは母語・第二言語の話者のうちインターネットを利用する人数の推計で、世界全体で重複を除いた実人数ではありません。一部の合算・欠損言語は、[CLDR 48 の言語人口](https://raw.githubusercontent.com/unicode-org/cldr/release-48/common/supplemental/supplementalData.xml)に[世界銀行のインターネット利用率（IT.NET.USER.ZS）](https://data.worldbank.org/indicator/IT.NET.USER.ZS)を掛け、比率による分割または補完推計を行っています。改変した並び順データにも [CC BY-SA 4.0 ライセンス](https://creativecommons.org/licenses/by-sa/4.0/)を適用します。

<a name="insights-language-versions-view"></a>

### サムネイル、タイトル、説明を確認

デフォルト: `結果の取得後に表示；説明は折りたたみ状態` | バージョン: `v2.0.0 (2026-09-14)`

結果は「サムネイル」と「タイトルと説明」の 2 つの領域に分かれ、それぞれ同じ内容をまとめ、各グループに含まれる言語を一覧表示します。異なる言語での内容の違いを素早く見つけるのに適しています。

異なるサムネイルは 1 行に 1 枚ずつ全幅で表示し、同じ画像はまとめます。サムネイルをクリックすると、新しいタブで画像が開きます。タイトルと説明は同じ組み合わせをまとめ、タイトルをクリックすると説明を開閉できます。同時に展開できるのは 1 件だけで、別の項目を展開すると、前の項目が自動で折りたたまれます。説明がない場合は「説明なし」と表示します。

進捗には取得済みの言語数と、まとめた後のバージョン数を表示します。バージョン数はサムネイル、タイトル、説明の完全な組み合わせで計算するため、サムネイルだけの数やテキストの組み合わせの数とは異なる場合があります。結果と展開した説明は内容に合わせて高さが増え、内部に個別のスクロールバーを設けず、ポップアップのメイン領域でスクロールします。

<a name="insights-language-versions-cache"></a>

### ローカルの取得結果を再利用

デフォルト: `動画ごとにこのブラウザー内に保存；有効期間は 60 分；ポップアップを開いたときに確認・削除` | バージョン: `v2.0.0 (2026-09-14)`

取得に成功した結果は自動でキャッシュされ、ポップアップを開き直したときに直接復元でき、重複した取得を減らせます。ポップアップを開いた際に現在の動画の有効なキャッシュが見つかると、その動画で引き続き有効なすべての言語の結果を、上記の有効期間で延長します。他の動画のキャッシュは延長せず、期限切れの結果が有効な状態に戻ることもありません。

ポップアップを開いたままにしている間は、キャッシュを定期的に削除しません。結果を復元した後は対応する言語を候補から除き、取得機能の選択ルールに従って残りの上位言語を選択します。すべての言語に有効なキャッシュがある場合は、候補言語を選択しません。

注意事項:

- ページ内には翻訳貢献者入口があり、翻訳の確認や参加がしやすくなっています。

<a name="general-update-notice"></a>

## 更新

<a name="general-update-notice-disable"></a>

### アップデート通知を無効にする

デフォルト: `オフ` | バージョン: `v1.2.1 (2026-07-21)`

有効にすると、拡張機能は拡張機能アイコン上の `new` マークで新バージョンの説明を読むよう通知しなくなり、未読の説明があるために拡張機能アイコンをクリックしたとき更新履歴が自動的に開くこともなくなります。

適した使用場面:

- 拡張機能アイコンに新バージョン説明のマークを表示したくない。
- 拡張機能アイコンをクリックするたびに、普段使用している設定ページを直接開きたい。

注意事項:

- このオプションを無効にしていると、未読の新バージョン説明が通知されます。
- 未読マークはバージョン番号の先頭 3 区分で判定します。4 番目のリビジョン番号だけが変わる更新では、`new` マークは再表示されません。
- このオプションは新バージョン説明の通知のみを無効にし、ブラウザーによる拡張機能の更新確認、ダウンロード、インストールを妨げません。
- 通知を無効にした後も、「情報」から更新履歴を手動で確認したり、バージョン番号をクリックして更新を手動確認したりできます。

<a name="general-update-notice-version"></a>

### 利用可能なアップデート通知

デフォルト: `新しいバージョンを検出すると自動表示` | バージョン: `v1.0.1 (2025-06-09)`

ブラウザーが拡張機能にインストール可能な新しいバージョンを検出すると、一般ページにアップデート通知が表示されます。

利用可能な操作:

- 更新履歴を見る。
- 今すぐ更新。

注意事項:

- 通常、すべての YouTube タブを閉じると、ブラウザーは拡張機能の更新を自動的に完了します。
- 「今すぐ更新」をクリックすると拡張機能が再読み込みされ、更新完了後に開いている YouTube タブが更新されます。
- 「アップデート通知を無効にする」は、未読の新バージョン説明の通知のみを無効にします。ブラウザーが利用可能なアップデートを検出したときに表示される通知は無効になりません。

<a name="general-update-notice-reload-page"></a>

### YouTube ページの再読み込みが必要な通知

デフォルト: `自動検出して通知` | バージョン: `v1.0.1 (2025-06-09)`

拡張機能の更新後、すでに開いている YouTube ページが古い状態をまだ使用している場合があります。完全に反映するために再読み込みが必要な設定を変更した場合も、再読み込みの通知が表示されます。通知が表示された後、再読み込みするタイミングは自分で決められます。

適した使用場面:

- 拡張機能が更新されたばかりだが、YouTube ページ内の機能が異常に見える。
- ページに拡張機能が更新済みで、再読み込みが必要と表示されている。
- 翻訳やロゴなどの設定を変更した後、すでに開いているページに新しい設定を適用したい。

利用可能な操作:

- 現在のページを再読み込み: 通知が表示されている YouTube ページのみを再読み込みします。
- すべての YouTube ページを再読み込み: 設定変更による通知に表示され、ブラウザー内で開いている YouTube タブを一括で再読み込みします。

注意事項:

- 設定パネルには個別のオプションがありません。
- 拡張機能の更新により接続が無効になった場合、通知には現在のページを再読み込みするボタンのみが表示されます。
- 再読み込みによりページの内容が読み直されるため、現在の閲覧操作が終わってからクリックできます。
- 再読み込み後、ページは新しい拡張機能状態を使用します。

<a name="general-update-notice-compatibility"></a>

### 互換性警告

デフォルト: `字幕翻訳または Premium ロゴへの偽装が有効なときに表示` | バージョン: `v1.1.3 (2025-12-03)`

字幕翻訳または Premium ロゴへの偽装を有効にしている場合、一般ページに警告表示が出ます。

理由:

- これらの機能は、YouTube がページに読み込む字幕またはブランド情報を直接調整します。
- この調整は YouTube の改版、ネットワーク問題、ブラウザー制限によってページ異常を引き起こす可能性があります。

推奨:

- 動画が再生できない、字幕が異常、ページ読み込みが異常、または Premium の購入、チャンネルメンバーへの参加、ライブ配信への投げ銭などの支払い関連ページに問題が発生した場合は、まず字幕翻訳と Premium ロゴへの偽装を無効にして確認してください。

<a name="general-config"></a>

## 拡張機能設定

<a name="general-config-export"></a>

### 設定をエクスポート

デフォルト: `通常設定のみをエクスポート；記憶は含まない` | バージョン: `v1.0.1 (2025-06-09)`

現在の拡張機能設定をテキストとしてエクスポートし、バックアップ、他のブラウザーへの移行、または他のユーザーとの共有に使えます。

設定可能な項目:

- 記憶も同時にエクスポート: クラウド同期の共通およびチャンネル別の倍速と字幕のオン/オフ状態に加え、ローカルに保存された動画別の字幕言語の記憶もバックアップします。

注意事項:

- 記憶オプションはクラウド同期の記憶とローカルの動画別記憶の両方が対象です。チェックしない場合は、どちらもエクスポートされません。
- エクスポートされた内容はクリップボードへコピーされます。コピーに失敗した場合は、手動でテキストを選択してコピーできます。
- カードの展開状態やインサイトのクエリキャッシュなど、ローカルの画面データはこのバックアップには含まれません。

<a name="general-config-import"></a>

### 設定をインポート

デフォルト: `通常設定のみをインポート；記憶は別途確認が必要` | バージョン: `v1.0.1 (2025-06-09)`

以前エクスポートした設定テキストを貼り付けて、現在のブラウザーへ設定を復元できます。

注意事項:

- インポートに失敗する場合、通常はテキスト形式が正しくないか、内容が不完全です。
- インポート内容にクラウド同期の記憶またはローカルの動画別記憶が含まれる場合、それらをインポートするか別途確認が必要です。確認しない場合は通常設定のみをインポートします。
- 確認後は、バックアップに含まれる記憶の種類ごとに、現在の対応する記憶を完全に置き換えます。統合はしません。バックアップ内のその種類が空の場合は、現在の対応する記憶も消去します。
- バックアップに含まれない種類の記憶は変更しません。例えば、ローカル記憶を含まない古いバックアップをインポートしても、既存の動画別字幕言語の記憶は消去されません。
- インポートした動画別字幕言語の記憶も、現在のブラウザー内にのみ保存され、クラウド同期には移行しません。

<a name="general-config-reset"></a>

### 設定をリセット

デフォルト: `通常設定を復元；既存の記憶は保持` | バージョン: `v1.0.0 (2025-05-19)`

拡張機能設定をデフォルト値へ戻せます。

注意事項:

- リセット前に確認プロンプトが表示されます。
- リセット後、パネルは「プレーヤー」ページへ戻ります。
- 通常設定のリセットでは、クラウド同期の記憶やローカルの動画別記憶は消去しません。記憶を移行または置き換える場合は、インポート/エクスポート内の記憶オプションを使用してください。

<a name="general-installed"></a>

## インストール歓迎ページ

<a name="general-installed-first-run"></a>

### 初回インストール案内

デフォルト: `初回インストール後に自動表示` | バージョン: `v1.0.0 (2025-05-19)`

拡張機能の初回インストール後、歓迎ページが開き、拡張機能が正常にインストールされたことを示し、ブラウザーの拡張機能アイコンをクリックして使い始めるよう案内します。ページは Safari、Chrome、Firefox、Edge、またはその他のブラウザーに応じて、矢印と拡張機能アイコンの案内位置やスタイルを調整します。

適した使用場面:

- 拡張機能をインストールしたばかりで、設定パネルをどこから開くか知りたい。
- 拡張機能がインストール完了していることを確認したい。

Safari 版の有効化と設定の入口:

- YouTweak をインストールした後、付属アプリを開いて有効化の案内を確認してください。アプリをインストールしただけでは、Safari 拡張機能は有効になりません。
- macOS では、「YouTweak 拡張機能を有効にする」または「YouTweak 拡張機能の設定を開く」をクリックすると、Safari の拡張機能設定が開き、有効化と管理を行えます。
- iPhone または iPad では、この 2 つのボタンからそれぞれ[有効化の案内](/docs/ja/help/ios.md#safari-enable)と[設定の入口の案内](/docs/ja/help/ios.md#safari-setting)が開きます。案内に従って操作してください。
- 続いて Safari で YouTube サイトを開き、Safari の案内に従って拡張機能によるサイトへのアクセスを許可してから、ブラウザーの拡張機能の入口で YouTweak の設定を開いてください。
- 付属アプリには、プロジェクトホームページ、問題報告、機能説明、更新履歴、ウェブサイトへの入口もあり、ヘルプを探すことができます。
